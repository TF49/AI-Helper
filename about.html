关于 Bob AI Helper

当前版本 v1.0.88 · 最后更新 2026-11-22

简短回答：Bob AI Helper（应用内显示为 AI Helper）是一款 MIT 开源的桌面工具，由 GitHub 用户 TF49 开发和维护，源码在 github.com/TF49/AI-Helper。它用来在 Windows 和 macOS 上配置 Cursor、Claude Code、OpenAI Codex CLI 等 AI 编程客户端的 API 地址、API Key 和模型。手动配置可以填写任意兼容的 API 服务；「一键配置」功能需要登录 Bob API 账号。

谁在维护

AI Helper 由 TF49 编写并维护，基于 Tauri 2、Rust、React 和 TypeScript 构建。版本发布记录见 GitHub Releases，问题反馈和功能建议请提交到 GitHub Issues。

和 Bob API 是什么关系

本站托管在 helper.bob-api.com。AI Helper 内置了 Bob API 账号登录，登录后可以使用「一键配置」：按客户端自动选择对应分组的 API Key 和推荐模型并写入配置。

不登录也可以使用 AI Helper。每个客户端面板都支持手动填写 API 地址、API Key 和模型，可以接入任何提供 Anthropic Messages、OpenAI Responses 或 Chat Completions 兼容接口的服务。AI Helper 客户端本身免费，模型调用按你所配置的 API 服务商计费。

AI Helper 怎么处理你的数据

  • API Key 只写入本机各客户端的配置文件，只会发送到你配置的 API 地址。
  • 登录会话凭据在 Windows 上用 DPAPI 加密，在 macOS 上存入钥匙串。
  • 首次修改某个客户端的配置前会保存快照，可以在设置页一键恢复。
  • 自动更新使用签名清单和 SHA-256 校验，下载源为官网、国内镜像和 GitHub Releases。

术语：一键配置中的「分组」是什么

「分组」指 Bob API 账号下用来给 API Key 归类的令牌分组名称，不是模型名。一键配置时，AI Helper 会按客户端选用对应分组的 Key；账号下没有该分组的 Key 时会自动创建。手动配置不涉及分组。

分组名称含义使用它的客户端一键配置的推荐模型
CC-Kiro-MaxClaude Code 专用令牌分组Claude Codeclaude-sonnet-5-5
Codex-不降质Codex 专用令牌分组OpenAI Codex CLI、ChatGPT Desktopgpt-5.6-sol
国产Token计划国产模型专用令牌分组Cursor、WorkBuddy、Accio Work、DeepSeek Harnessglm-5.3；DeepSeek Harness 写入该 Key 下全部可对话模型，默认 deepseek-v4.1-flash

名称说明

还有其他产品也叫「AI Helper」，例如 Discourse 论坛插件和一些浏览器扩展。本站介绍的 Bob AI Helper（应用内显示为 AI Helper）是发布在 helper.bob-api.com 和 github.com/TF49/AI-Helper 的桌面配置工具，与它们无关。
