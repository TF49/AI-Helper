Bob AI Helper 使用教程

最后更新 2026-11-24

Bob AI Helper（简称 AI Helper）是一款 MIT 开源、本地运行的桌面工具，用于在 Windows 和 macOS 上一键配置 Cursor、Claude Code、OpenAI Codex CLI、ChatGPT Desktop、WorkBuddy、Accio Work 与 DeepSeek Harness 的 API 地址、API Key 和模型。AI Helper 配合 Bob API 服务使用，可选 BobAPI 官方节点或 TaijiAI 备用节点。下面每篇教程回答一个具体问题。English guides: helper.bob-api.com/en/guides.

配置教程

  • 如何给 Cursor 配置 glm-5.3 等第三方模型

    为什么只改 OpenAI Base URL 不够，以及如何通过本地 Bridge（127.0.0.1:8969）接入 BobAPI 上的 glm-5.3 等模型。

  • Claude Code 如何切换 API 地址与模型

    修改 ~/.claude/settings.json 中的 ANTHROPIC_BASE_URL、ANTHROPIC_AUTH_TOKEN 与 ANTHROPIC_MODEL。

  • OpenAI Codex CLI 如何配置自定义 API 地址

    在 ~/.codex/config.toml 中声明自定义 model_providers，并设置 API Key 环境变量。

  • DeepSeek Harness 怎么接入 Claude、GPT 和国产模型

    一个 API Key 按协议自动写入 aihelper-claude、aihelper-codex、aihelper-cn 三条路由，自建路由与 DeepSeek 官方账号原样保留。

  • WorkBuddy 如何配置自定义 API 与多个模型

    在 ~/.workbuddy/models.json 中维护多个模型，推荐模型排在最前，已有模型原样保留。

  • Accio Work 如何接入第三方模型（本地 Bridge）

    通过本地 Bridge（默认 127.0.0.1:8787）注入模型列表，把请求转换为 OpenAI / Anthropic 兼容接口。

参考与排错

  • AI 编程客户端配置文件路径与环境变量大全（Windows & macOS）

    7 款客户端与 AI Helper 自身的配置文件路径、关键字段、环境变量和 Bridge 端口速查表。

  • Cursor 自定义模型不生效 / 第三方模型连不上怎么排查

    按 Bridge 运行状态、端口占用、补丁被 Cursor 更新覆盖、模型工具调用能力逐项排查。

  • Claude Code 报 401 / 超时 / 连不上自定义 API 怎么办

    区分 401、403、404 与超时；检查 ANTHROPIC_BASE_URL 末尾 /v1、认证变量冲突与系统环境变量。

  • Codex CLI 修改 config.toml 不生效怎么排查

    检查 model_provider 与 model_providers、base_url、env_key 环境变量、profile 覆盖与 TOML 语法。

  • macOS 打开 AI Helper 提示“已损坏”怎么办

    用 xattr -cr 清除 Gatekeeper 隔离标记，或右键选择「打开」。
