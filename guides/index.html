AI Helper 使用教程

最后更新 2026-11-20

AI Helper 是一款 MIT 开源的桌面工具，用于在 Windows 和 macOS 上一键配置 Cursor、Claude Code、OpenAI Codex CLI、ChatGPT Desktop、WorkBuddy 与 Accio Work 的 API 地址、API Key 和模型。下面每篇教程回答一个具体问题。

  • 如何给 Cursor 配置 glm-5.3 等第三方模型

    为什么只改 OpenAI Base URL 不够，以及如何通过本地 Bridge（127.0.0.1:8969）接入任意 OpenAI 兼容模型。

  • Claude Code 如何切换 API 地址与模型

    修改 ~/.claude/settings.json 中的 ANTHROPIC_BASE_URL、ANTHROPIC_AUTH_TOKEN 与 ANTHROPIC_MODEL。

  • OpenAI Codex CLI 如何配置自定义 API 地址

    在 ~/.codex/config.toml 中声明自定义 model_providers，并设置 API Key 环境变量。

  • macOS 打开 AI Helper 提示“已损坏”怎么办

    用 xattr -cr 清除 Gatekeeper 隔离标记，或右键选择「打开」。

没有找到答案？可以查看 首页常见问题，或到 GitHub Issues 提问。
