DeepSeek Harness 怎么接入 Claude、GPT 和国产模型

适用于 AI Helper v1.0.87 · Windows 与 macOS · 最后更新 2026-11-21

简短回答：DeepSeek Harness（DSH）桌面版的模型路由写在 ~/.dsh/profiles/desktop/cordis.patch.yml，对应的 API Key 写在同目录体系下的 .credentials.yaml。Claude、GPT 和国产模型使用三种不同的协议，需要分别配置路由。AI Helper 可以用一个 API Key 拉取全部可用模型，按协议自动写入 aihelper-claude、aihelper-codex、aihelper-cn 三条路由，并保留你的自建路由、注释和 DeepSeek 官方账号。

为什么不同模型要写进不同路由

DeepSeek Harness 的每条路由只对应一种接口协议。同一个 API Key 下的模型，协议可能各不相同，所以 AI Helper 会按协议把模型分到下面三条路由：

路由DSH 中的显示名称协议适用模型
aihelper-claudeAI Helper · ClaudeAnthropic MessagesClaude 系列
aihelper-codexAI Helper · CodexOpenAI ResponsesGPT / Codex 系列
aihelper-cnAI Helper · 国产模型OpenAI Chat CompletionsDeepSeek、Qwen、GLM 等国产模型

协议由 AI Helper 自动判定，你只需要勾选模型。写入的模型默认声明支持文本和图片输入；保存后没有模型的托管路由会被自动移除。

使用前的准备

  1. 先启动一次 DeepSeek Harness 桌面版，让它在 ~/.dsh 下生成 desktop 档案。如果你设置了 DSH_HOME 环境变量，AI Helper 会优先读取该目录。
  2. 在 AI Helper 的 设置 → 路径管理 中点击「探测」，确认 DeepSeek Harness 的安装路径已就绪。AI Helper 会依次检查运行中的进程、Windows 注册表、%LOCALAPPDATA%\Programs 和 macOS 的 /Applications；也可以手动选择 DeepSeek Harness.exe 或 DeepSeek Harness.app。

方法一：工作台一键配置

登录 Bob API 账号后，在工作台大厅点击 DeepSeek Harness 卡片的一键配置。AI Helper 会使用「国产Token计划」分组的 API Key（账号下没有时自动创建），写入该 Key 下全部可对话模型，并把新会话的默认模型设为 deepseek-v4.1-flash。「一键配置所有」的批量终端同样包含 DeepSeek Harness，会按协议逐条测试各路由，全部通过后一次写入。

方法二：配置向导手动接入

  1. 打开 配置中心 → DeepSeek Harness。
  2. 填写接入节点。默认是 https://bob-api.com/，也可以填写你自己的服务网关节点。
  3. 填入 API Key。AI Helper 会拉取这个 Key 当前分组下的全部可用模型，并自动过滤图像、语音、向量等无法对话的模型。
  4. 勾选要接入的模型，支持全选，也可以手动添加模型 ID；然后选择新会话的默认模型。默认模型只影响新会话，在 DeepSeek Harness 里随时可以切换。
  5. AI Helper 对每条路由做连通性测试，全部通过后才统一写入；任一路由失败都不会落盘。
  6. 保存后重启 DeepSeek Harness（可以在测试终端或路径管理卡片里直接点击重启），在模型选择器中就能看到「AI Helper · 国产模型」等新路由。

同时使用多个分组的 Key

不同分组的 Key 可以分别保存、同时生效，例如国产分组 Key、Claude 分组 Key 和 GPT 分组 Key 并存：

  • 添加其它分组的 Key：在配置概览中点击「添加其它分组的 Key」，新 Key 与已接入的 Key 并存，默认只勾选尚未接入的模型类型。
  • 更换 Key：新 Key 接管被替换 Key 的路由，其它 Key 已接入的路由保持不变。
  • 编辑单个 Key：从概览进入向导时，只编辑使用该 Key 的路由。
  • 重新核对：在 bob-api 网页切换分组后，可以在概览中一键重新查询各路由的模型是否仍然可用。

AI Helper 会改动哪些内容

AI Helper 只管理自己的 aihelper-* 路由和 AIHELPER_* 密钥引用，其它内容保持原样：

  • 只读写 desktop 档案，CLI、Web 等其它档案不会被修改。
  • 按行编辑，你的自建路由、records、注释和 !!js 表达式逐字节保留；每次写入前都会和原文件做语义比对，确认只改了该改的部分。
  • 与 DeepSeek Harness 共用写锁，避免和 DSH 自身（例如刷新官方账号 Token）同时写文件。
  • DeepSeek 官方账号登录和官方 API Key 路由（api.deepseek.com）不会被改写；如果你的默认模型指向官方模型，保存时也保持不变。
AI Helper 首次接管前会保存配置快照。在设置页重置客户端配置时，托管路由和密钥引用会恢复到快照状态，DeepSeek Harness 的令牌绑定记录也会一并清理。

常见问题

保存后在 DeepSeek Harness 里看不到新模型？

DeepSeek Harness 在启动时读取配置，保存后需要重启客户端才能加载新路由。AI Helper 重启时会先向主进程发送优雅退出请求，不会再弹出 “renderer exited: killed” 崩溃框。

提示“分组不可用”是什么意思？

说明该模型此前配置过，但已不在这个 Key 当前所属的分组中，常见于在 bob-api 网页切换了分组，中转站会返回 model_not_found。请重新拉取可用模型、取消勾选不可用的模型，或在网页上把 Key 切回原分组。你手动添加的模型 ID 不会被自动取消勾选。

提示“未找到 DeepSeek Harness 桌面版配置”？

请先启动一次 DeepSeek Harness 桌面版完成初始化，它会在 ~/.dsh（或 DSH_HOME 指定的目录）下生成配置档案，之后回到 AI Helper 即可正常配置。

会影响我的 DeepSeek 官方账号吗？

不会。官方账号登录、官方 API Key 路由以及你自建的路由都原样保留，AI Helper 只写入它自己托管的 aihelper-* 路由。
