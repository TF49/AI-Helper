OpenAI Codex CLI 如何配置自定义 API 地址

适用于 AI Helper v1.0.88 · Windows 与 macOS · 最后更新 2026-11-24 · 作者 TF49

简短回答：在 ~/.codex/config.toml 中声明 [model_providers.custom]（写入 base_url 和 env_key），把顶层 model_provider 指向它、model 设为模型名，Key 放进 CUSTOM_OPENAI_API_KEY。MIT 开源的 AI Helper 可以在选择 BobAPI 官方节点（或 TaijiAI 备用节点）并填入 API Key 和模型后，在本机自动写入这些字段。

方法一：手动修改 config.toml

打开（或新建）~/.codex/config.toml，Windows 上对应 C:\Users\你的用户名\.codex\config.toml：

model = "gpt-5.6-sol"
model_provider = "custom"

[model_providers.custom]
base_url = "https://bob-api.com/v1"
env_key = "CUSTOM_OPENAI_API_KEY"

然后把 API Key 设到环境变量 CUSTOM_OPENAI_API_KEY 中（Windows 可在「系统属性 → 环境变量」中添加用户变量；macOS / Linux 可写入 shell 配置文件），重新打开终端后运行 codex。

方法二：用 AI Helper 一键配置

  1. 启动 AI Helper，进入 Codex 面板，AI Helper 会自动探测 codex CLI 的位置。
  2. 选择接入节点：「BobAPI 官方节点」（https://bob-api.com/，推荐首选）或「TaijiAI 加速节点」（https://taijiai.online/，备用专线），输入 API Key，选择模型（例如 gpt-5.6-sol）。手动填写的 Key 首次用于某个节点时，需点击「确认用于此节点」；从 Bob API 账号选择的 Key 和一键配置只能用于 BobAPI 官方节点。
  3. 点击「确认并保存 Codex 配置」，流式连通性测试通过后写入。AI Helper 会写入上面示例中的字段；在 Windows 上，它还会把 Key 写入当前用户的 CUSTOM_OPENAI_API_KEY 环境变量并通知系统刷新。macOS 上不会修改 shell 配置文件，需要自行设置该环境变量（见下方常见问题）。
  4. 重新打开终端并运行 codex，或直接在 AI Helper 中启动 Codex。
config.toml 中的内容AI Helper 的处理
model写入所选模型
model_provider设为 "custom"
[model_providers.custom] 的 base_url写入所选节点的地址，自动补上 /v1
[model_providers.custom] 的 env_key固定为 CUSTOM_OPENAI_API_KEY
custom 中的 experimental_bearer_token、Authorization 等凭据请求头移除，Key 只从环境变量读取
其他 provider、profile、sandbox 等设置原样保留
AI Helper 只管理名为 custom 的 provider。你在 config.toml 中定义的其他 provider、profile、sandbox 设置都会保留。登录 Bob API 账号使用「一键配置」时，Codex 会使用「Codex-不降质」分组（Bob API 账号下 Codex 专用的令牌分组，分组说明）的 Key，推荐模型为 gpt-5.6-sol。

如何恢复原来的配置

AI Helper 首次修改 Codex 配置前会保存快照，包括 config.toml 和相关环境变量。在设置页使用一键恢复即可还原。

常见问题

Codex 提示找不到 API Key？

Codex 从 env_key 指定的环境变量读取 Key。已打开的终端不会自动获得新设置的环境变量，请关闭后重新打开终端。

返回 model_not_found？

说明当前 API Key 所在的分组不提供该模型。请从 AI Helper 读取到的模型列表中重新选择模型。

macOS 上在终端运行 codex，为什么读不到 Key？

只有在 Windows 上，AI Helper 才会把 Key 持久写入当前用户的 CUSTOM_OPENAI_API_KEY 环境变量。macOS 上 AI Helper 不会修改你的 shell 配置文件，请自行在 ~/.zshrc 等文件中加入 export CUSTOM_OPENAI_API_KEY="你的 API Key"，然后重新打开终端。

保存时提示“Codex 活动 profile 使用其他 provider”？

说明 config.toml 顶层的 profile 指向了一个使用其他 model_provider 的 profile。为避免界面显示的配置与 Codex 实际运行的目标不一致，AI Helper 会停止保存。请先切换到使用 custom 的 profile，或移除顶层 profile 设置后再保存。
