Claude Code 报 401 / 超时 / 连不上自定义 API 怎么办

适用于 AI Helper v1.0.88 · Windows 与 macOS · 最后更新 2026-11-24 · 作者 TF49

简短回答：先看状态码：401 是 Key 不对或被另一组环境变量覆盖；403 是账号无权访问该模型或被访问管控；404 多半是 ANTHROPIC_BASE_URL 多写了 /v1 或模型名不对；超时和连接失败是网络或代理问题。Claude Code 的 ANTHROPIC_BASE_URL 应填服务根地址（不带 /v1），Key 只保留 ANTHROPIC_AUTH_TOKEN 或 ANTHROPIC_API_KEY 其中一个。用 AI Helper 的连通性测试可以先排除 Key、地址和模型的问题，剩下的就是本机环境变量与网络。

症状、原因与处理速查

症状常见原因处理方法
HTTP 401Key 填错、过期或被吊销；Key 与该 API 地址不匹配；系统环境变量中另一组 Key 生效；网关只接受某一种认证请求头核对 Key；清理多余的 ANTHROPIC_API_KEY / ANTHROPIC_AUTH_TOKEN；重新启动 claude

一、先用连通性测试定位问题

AI Helper（MIT 开源、在本机运行）在保存 Claude Code 配置之前会做一次连通性测试：向所选节点的 /v1/messages 发送一条 max_tokens: 16 的 “Hi” 消息，超时时间 60 秒。测试日志会显示目标端点、测试模型、打码后的 Key、HTTP 状态码、耗时和上游返回的错误详情，并针对状态码给出建议。测试不通过时，AI Helper 不会修改本地配置。

判断方法很简单：

  • 测试也失败：问题出在 Key、地址、模型或网络本身，按下面的状态码逐项处理。
  • 测试通过但 Claude Code 失败：问题通常出在本机——ANTHROPIC_BASE_URL 带了 /v1、另一组环境变量生效、会话没有重启，或终端的代理设置与 AI Helper 不同。
AI Helper 的测试用 x-api-key 请求头发送 Key，而它写入的 ANTHROPIC_AUTH_TOKEN 在 Claude Code 中以 Authorization: Bearer 请求头发送。绝大多数 Anthropic 兼容网关两种都接受；如果某个网关只接受其中一种，测试结果就可能与 Claude Code 中的实际表现不一致。

二、401、403、404 分别是什么问题

401：身份认证失败

  • Key 是否完整复制、是否已过期或被禁用。登录 Bob API 账号后也可以用「一键配置」，由 AI Helper 从对应分组中选取 Key。
  • 是否同时存在两组凭据：ANTHROPIC_AUTH_TOKEN 以 Authorization: Bearer 发送，ANTHROPIC_API_KEY 以 x-api-key 发送。AI Helper 只写入 ANTHROPIC_AUTH_TOKEN；如果系统环境变量或 settings.json 中还留着旧的 ANTHROPIC_API_KEY，容易出现认证冲突或用错 Key。建议只保留一个。
  • 系统或终端里是否设置了另一个 ANTHROPIC_AUTH_TOKEN，见第四节。

403：访问被拒绝

Key 本身有效，但当前账号没有权限访问该模型，或节点做了访问管控（例如 IP 地域限制）。换一个有权限的模型或 Key，或在 Bob API 账号中确认 Key 所属分组。

404：端点或模型不存在

最常见的原因是 ANTHROPIC_BASE_URL 格式不对，见下一节；其次是地址拼错，或模型名在该服务中不存在。

三、ANTHROPIC_BASE_URL 的格式：不要带 /v1

Claude Code 会在 ANTHROPIC_BASE_URL 后面自己拼接 /v1/messages，所以应填写服务的根地址：

正确：https://bob-api.com
正确：https://bob-api.com/
错误：https://bob-api.com/v1      → 实际请求 /v1/v1/messages，通常返回 404

这个问题通常出现在手动编辑 ~/.claude/settings.json 之后。AI Helper 写入的是所选节点的根地址（https://bob-api.com/ 或 https://taijiai.online/），不带 /v1。如果你手动改成了带 /v1 的地址，去掉末尾的 /v1，或在 AI Helper 中切换回 BobAPI 官方节点重新保存即可。另外，配置文件里原有的地址会在面板中显示为「当前自定义」；它带 /v1 时，AI Helper 的连通性测试会先去掉末尾的 /v1，可能出现“测试通过、Claude Code 报 404”，同样切换到 BobAPI 官方节点重新保存即可。

AI Helper 写入的内容如下，settings.json 中的其他字段（例如 permissions、hooks、env 中的其他变量）保持不变：

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://bob-api.com/",
    "ANTHROPIC_AUTH_TOKEN": "你的 API Key",
    "ANTHROPIC_MODEL": "claude-sonnet-5-5"
  },
  "model": "claude-sonnet-5-5"
}

四、改了配置不生效：检查环境变量与会话

  • 重新启动会话。Claude Code 在启动时读取配置，已经打开的 claude 会话不会自动切换到新地址，需要完全退出后重新运行。
  • 检查同名的系统环境变量。如果系统或 shell 配置文件里也设置了 ANTHROPIC_BASE_URL、ANTHROPIC_AUTH_TOKEN、ANTHROPIC_API_KEY 或 ANTHROPIC_MODEL，两处取值不一致时很难判断哪一个在起作用。建议只在 settings.json 的 env 中保留一份。 
    # Windows（PowerShell）
Get-ChildItem Env: | Where-Object Name -like "ANTHROPIC*"

# macOS
env | grep ANTHROPIC
  • 检查其他设置文件。Claude Code 还会读取项目目录下的 .claude/settings.json 和 .claude/settings.local.json，同名设置按官方文档中的优先级合并。在某个项目里“不生效”时，检查该项目目录下是否也写了 env。
  • 确认文件是合法 JSON。现有 settings.json 无法解析时，AI Helper 会停止写入并提示“现有 Claude 配置损坏，已停止写入以免丢失安全规则”，需要先修复格式。

五、超时与连接失败：检查网络、代理与 HTTPS

AI Helper 测试中出现“请求超时 (超过 60 秒未收到响应)”或“网络连接失败: 无法连接至服务节点”时，说明请求没有拿到 HTTP 响应，与 Key 无关：

  • 确认本机能访问所选节点，例如在浏览器或 curl 中打开 https://bob-api.com/；一个节点不通时，可以在 AI Helper 中切换到 TaijiAI 加速节点后重新测试，但该节点只接受手动填写并已确认用于该节点的 Key，从 Bob API 账号选择的 Key 会被拒绝（见下方常见问题）。手动编辑过 settings.json 的，还要确认 ANTHROPIC_BASE_URL 拼写正确。
  • 如果需要通过代理访问，Claude Code 会读取终端中的 HTTPS_PROXY / HTTP_PROXY 环境变量。AI Helper 测试通过但 Claude Code 超时，往往是终端里没有设置代理，或代理设置与系统不同。
  • 连接必须使用 HTTPS，两个预置节点都满足。AI Helper 不会把 Key 发往 http:// 开头的远程地址（例如配置文件中原有的 HTTP 地址），会提示“远程节点仅允许 HTTPS”。

常见问题

ANTHROPIC_BASE_URL 要不要带 /v1？

不要。Claude Code 会在 ANTHROPIC_BASE_URL 后面自己拼接 /v1/messages，所以应填写服务根地址，例如 https://bob-api.com。手动把 settings.json 改成 https://bob-api.com/v1 时，实际请求会变成 /v1/v1/messages，通常返回 404。去掉末尾的 /v1，或在 AI Helper 中切换回 BobAPI 官方节点重新保存即可，AI Helper 写入的是不带 /v1 的根地址。

ANTHROPIC_AUTH_TOKEN 和 ANTHROPIC_API_KEY 有什么区别？能同时设置吗？

ANTHROPIC_AUTH_TOKEN 以 Authorization: Bearer 请求头发送，ANTHROPIC_API_KEY 以 x-api-key 请求头发送。AI Helper 只写入 ANTHROPIC_AUTH_TOKEN。如果系统环境变量或 settings.json 里还留着另一个服务的 ANTHROPIC_API_KEY，两个凭据会同时存在，容易导致认证冲突或用错 Key，建议只保留一个。

AI Helper 测试通过，但 Claude Code 里仍然 401 怎么办？

AI Helper 的测试用 x-api-key 请求头发送 Key，而 Claude Code 使用 ANTHROPIC_AUTH_TOKEN 时发送的是 Authorization: Bearer 头。先检查系统环境变量里是否有另一组 ANTHROPIC_API_KEY 或 ANTHROPIC_AUTH_TOKEN，再确认网关同时接受这两种请求头；最后完全退出并重新启动 claude。

一个节点超时或连不上，可以换节点吗？

可以，但 TaijiAI 加速节点需要手动填写的 Key。AI Helper 的 Claude Code 面板提供两个接入节点：BobAPI 官方节点（https://bob-api.com/，推荐首选）和 TaijiAI 加速节点（https://taijiai.online/，备用专线），都使用 HTTPS。从 Bob API 账号选择的 Key、一键配置使用的 Key，以及已确认用于 BobAPI 官方节点的 Key，都只能发往 BobAPI 官方节点；改用 TaijiAI 加速节点时，需要手动填写 Key，并在密钥输入处点击「确认用于此节点」。切换节点后重新测试并保存，然后重新启动 claude。
