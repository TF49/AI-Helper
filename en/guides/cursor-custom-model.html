How to use glm-5.3 and other third-party models in Cursor

For AI Helper v1.0.88 · Windows & macOS · Last updated 2026-11-24 · By TF49

Short answer: Changing the OpenAI base URL isn't enough, because Cursor talks over Connect-RPC / HTTP2. AI Helper, an MIT-licensed open-source app, runs a bridge on your machine (127.0.0.1:8969 by default) that translates Cursor's requests and forwards them to the BobAPI node with your API key — so Cursor can use glm-5.3 and other models available on BobAPI.

AI Helper's interface is currently in Chinese. Button names in this guide are translated, with the original label in parentheses.

Before you start

  • Cursor is installed and has been launched at least once.
  • You have a BobAPI API key, or a Bob API account you can sign in to for one-click setup.
  • AI Helper is installed (download — Windows 10/11 or macOS 11+).

Step by step

  1. Open the Cursor panel. Launch AI Helper. The home screen detects where Cursor is installed; open the Cursor configuration panel.
  2. Choose a node and enter your key. Pick the BobAPI official node (BobAPI 官方节点, https://bob-api.com/, recommended) or the TaijiAI accelerated node (TaijiAI 加速节点, https://taijiai.online/, a backup line), then enter your API key — or sign in to a Bob API account and use one-click setup. The first time you use a hand-entered key with a node, click Confirm for this node (确认用于此节点). Keys picked from your Bob API account, and one-click setup, only work with the BobAPI official node.
  3. Pick a model. AI Helper fetches the model list from the selected node. Choose glm-5.3 or another model from the list, or type a model name by hand.
  4. Save the configuration. Click Confirm and save Cursor config (确认并保存 Cursor 配置). Once the connection test passes, AI Helper writes the settings to ~/.ai-helper/cursor_config.json and starts the local bridge.
  5. Connect AI Helper. In the client status area of the panel, click Connect AI Helper (接入 AI Helper). This patches the Cursor client so its requests go to the bridge.
  6. Restart Cursor. Click Restart Cursor (重启 Cursor), then select the model you just configured in Cursor's model picker.

If you sign in to AI Helper with a Bob API account and use one-click setup, Cursor automatically gets an API key from the 国产Token计划 group — the key group in a Bob API account reserved for Chinese models (see key groups, in Chinese). The recommended model is glm-5.3. If your account has no key in that group yet, AI Helper creates one.

What the bridge supports

  • Two-way translation between Cursor's requests and OpenAI-style requests, including streaming responses.
  • Text, reasoning output and image input.
  • Serving the list of available models and the default model to Cursor.
  • Letting Cursor Agent read and search files in the current workspace. Writing or deleting files requires you to authorize that workspace in the panel first (authorizations are stored in ~/.ai-helper/agent_workspaces.json).

When you close the AI Helper main window, the app stays in the system tray and the bridge keeps running. The bridge only stops when you quit AI Helper from the tray — at that point, third-party models in Cursor stop working.

Security measures

The bridge only listens on the loopback address. For the first request on each connection, it looks up which process opened the connection (by its source port) and only accepts processes running as the same OS user as AI Helper; if the owner cannot be determined, the connection is rejected. It also validates the Host, Origin and Content-Type headers.

How to switch back to Cursor's official connection

Click Restore official connection (恢复官方连接) in the Cursor panel, or use one-click restore on AI Helper's Settings page. The bridge is stopped and the patch to the Cursor client is reverted.

FAQ

Port 8969 is already in use. What should I do?

Change the bridge port in the Cursor panel to another free port, save, and click Restart Cursor. If Cursor is already connected to AI Helper, the client is re-patched for the new port before it restarts.

Third-party models stopped working after a Cursor update. Why?

A Cursor update can overwrite the patched files. Open the Cursor panel in AI Helper; if the status shows a direct official connection, click Connect AI Helper to re-apply the patch, then restart Cursor.

Can Cursor still use third-party models after I close the AI Helper window?

Yes. Closing the main window leaves AI Helper running in the system tray, and the bridge keeps running. The bridge only stops when you quit AI Helper from the tray; at that point, third-party models in Cursor stop working.

Cursor Agent says the workspace is not authorized when it edits files. What should I do?

The bridge only lets Cursor Agent write or delete files in workspaces you have authorized. Open the Cursor panel in AI Helper, click Allow on the pending request, and try again. Authorizations are stored in ~/.ai-helper/agent_workspaces.json and can be revoked under authorized workspaces.
