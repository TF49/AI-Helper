Bob AI Helper guides

For AI Helper v1.0.88 · Last updated 2026-11-24

Bob AI Helper (shown in the app as AI Helper) is a free, MIT-licensed desktop app for Windows and macOS that sets the API endpoint, API key and model for Cursor, Claude Code, OpenAI Codex CLI, ChatGPT Desktop, WorkBuddy, Accio Work and DeepSeek Harness. Each guide below answers one specific question, and most also show how to do the same thing by hand.

  • How to use glm-5.3 and other third-party models in Cursor

    Why changing the OpenAI base URL isn't enough, and how the local bridge (127.0.0.1:8969) connects Cursor to glm-5.3 and other models available on BobAPI.

  • How to change the API endpoint and model in Claude Code

    Set ANTHROPIC_BASE_URL, ANTHROPIC_AUTH_TOKEN and ANTHROPIC_MODEL in ~/.claude/settings.json.

  • How to use a custom API endpoint with OpenAI Codex CLI

    Declare a custom model_providers entry in ~/.codex/config.toml and set the API key environment variable.

  • How to connect DeepSeek Harness to Claude, GPT and Chinese models

    One BobAPI key, split by protocol across the aihelper-claude, aihelper-codex and aihelper-cn routes — your own routes and official DeepSeek account stay untouched.

  • macOS says AI Helper “is damaged and can't be opened” — how to fix it

    Clear the Gatekeeper quarantine flag with xattr -cr, or Control-click the app and choose Open.
