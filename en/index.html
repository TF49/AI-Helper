AI Helper: configure Cursor, Claude Code and Codex in one place

Version v1.0.88 · Windows & macOS · MIT license · Last updated 2026-11-22

AI Helper is a free, open-source (MIT) desktop app for Windows and macOS that sets the API endpoint, API key and model for seven AI coding clients — Cursor, Claude Code, OpenAI Codex CLI, ChatGPT Desktop, WorkBuddy, Accio Work and DeepSeek Harness. It finds the clients installed on your machine, writes their config files, runs a real streaming connection test, and restarts the client so the change takes effect.

Download AI Helper

What it does

  • Detects clients automatically — scans PATH, the Windows registry, npm global installs, Microsoft Store apps, Homebrew and NVM on macOS.
  • Writes config safely — only endpoint, key and model fields are changed; other settings are preserved. Files are written atomically with locking, and a snapshot is taken before the first change so you can restore it from Settings.
  • Tests before saving — sends a real streaming request and reports the HTTP status, time to first byte and common error hints.
  • Connects Cursor to third-party models — a local bridge (default 127.0.0.1:8969) translates Cursor's Connect-RPC / HTTP2 traffic to an OpenAI-compatible API, with streaming, reasoning output and image input.
  • Bridges Accio Work — a local bridge (default 127.0.0.1:8787) adapts model lists, chat, image generation, the Responses API and MCP proxying.
  • Splits one key across DeepSeek Harness routes — fetches every chat model your API key can use and writes it to the matching route by protocol: aihelper-claude (Anthropic Messages), aihelper-codex (OpenAI Responses) or aihelper-cn (Chat Completions, for DeepSeek, Qwen, GLM and other Chinese models). Edits are line-level, so your own routes, comments, !!js tags and the official DeepSeek account are kept.
  • Signed updates — update manifests are signature-checked, SHA-256 verified and protected against rollback.

Privacy and security

All configuration is written on your machine. Session credentials are protected with DPAPI on Windows and Keychain on macOS. Your API key is only sent to the endpoint you configure, and endpoints outside the allow-list must be confirmed (HTTPS required by default). The Cursor bridge only accepts connections from processes owned by the same OS user.

FAQ

Can I use my own API endpoint and API key?

Yes. Every client panel accepts a custom API base URL, API key and model, and can fetch the model list from that endpoint. Unknown origins must be confirmed and HTTPS is required by default.

Why does Cursor need a local bridge?

Cursor uses Connect-RPC / HTTP2 and internal message formats, so changing the OpenAI base URL alone cannot connect every third-party model. AI Helper runs a local bridge (default 127.0.0.1:8969) that translates Cursor requests to an OpenAI-compatible API. The client patch can be reverted at any time.

Does configuring DeepSeek Harness touch my official DeepSeek account?

No. AI Helper only writes its own aihelper-* routes and AIHELPER_* key references in the DeepSeek Harness desktop profile. The official DeepSeek account sign-in, the official API-key route (api.deepseek.com) and your own routes are left as they are, and a default model that points at an official model is kept. Restart DeepSeek Harness after saving to load the new routes.

Is my API key uploaded anywhere?

No. Configuration is written locally. Session credentials are protected with DPAPI on Windows and Keychain on macOS. Your API key is only sent to the API endpoint you configure.

Is AI Helper free?

Yes. AI Helper is open source under the MIT license and free to use. Model usage is billed by whichever API provider you configure.

macOS says the app "is damaged and can't be opened". What do I do?

The app is not damaged; it is not notarized by Apple, so Gatekeeper quarantines it. Run xattr -cr /Applications/AI\ Helper.app in Terminal, or right-click the app in Finder and choose Open.
