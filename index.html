这里汇总了开发者最关心的关键事项，让你用得彻底放心。

AI Helper 是 100% 自由开源软件，遵循宽松的 MIT 开源协议。无论是个人开发者、团队协作还是企业内网使用，均完全免费，永久承诺不含任何广告弹窗，亦没有任何付费墙功能。
绝对安全！AI Helper 所有配置下发操作均在本地进行，直接原子读写你本地的配置文件（如 ~/.claude.json、~/.codex/config.toml、以及 ~/.workbuddy-ai/models.json）。除向你指定的 API 网关发起流式连通性测试握手外，绝不向任何第三方云端或遥测服务器上传你的任何凭证。全部代码均开源可供审计。
这是因为开源项目的安装包由 GitHub Actions 自动化编译发布，未向商业机构购买昂贵的高级 EV 代码签名证书（SmartScreen 对新发布的二进制会触发此标准拦截）。请放心点击界面上的「更多信息」➔「仍要运行」即可。你也可以随时通过便携免安装版（ZIP）直接解压运行。
我们在下载专区直接提供了「🚀 国内高速镜像下载」按钮（基于稳定 CDN 反代加速）。点击该按钮即可绕过 GitHub 官方直连瓶颈，实现满速秒级下载。
AI Helper 全面引入了对 Workbuddy AI 自定义模型的专有支持。在界面中选择 WorkBuddy 标签页，填入你的自定义模型名称（如 gpt-5.6-sol、claude-3-7-sonnet）及 Base URL，点击保存即可由 Rust 后端自动直写入本地配置并热重载生效，启动 WorkBuddy 后无需复杂配置直接可用！
