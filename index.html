AI Helper. AI 编程客户端的 API 与模型， 在一个桌面工具里配好。

AI Helper 是一款 MIT 开源的桌面工具，用于在 Windows 和 macOS 上一键配置 Cursor、Claude Code、OpenAI Codex CLI、ChatGPT Desktop、WorkBuddy、Accio Work 与 DeepSeek Harness 的 API 地址、API Key 和模型。它会自动找到本机已安装的客户端，写入配置后做一次流式连通性测试，再帮你重启客户端；Cursor 和 Accio Work 通过内置的本地 Bridge 接入第三方模型，DeepSeek Harness 用一个 Key 按协议自动分流到 Claude、GPT 与国产模型路由。

FAQ

常见问题与解答。

关于 macOS 安装、架构选择、费用、隐私与网络连接，你关心的都在这里。

AI Helper 是一款 MIT 开源的桌面工具，用于在 Windows 和 macOS 上统一配置 AI 编程客户端的 API 地址、API Key 和模型。它支持 Cursor、Claude Code、OpenAI Codex CLI、ChatGPT Desktop、WorkBuddy、Accio Work 和 DeepSeek Harness，会自动探测这些客户端、写入它们的本地配置文件、做流式连通性测试，并在需要时启动或重启客户端。

目前支持 7 款：Claude Code（~/.claude/settings.json）、OpenAI Codex CLI（~/.codex/config.toml）、Cursor（~/.ai-helper/cursor_config.json，经本地 Bridge 接入）、WorkBuddy（~/.workbuddy/models.json）、Accio Work（~/.ai-helper/accio_config.json，经本地 Bridge 接入）、DeepSeek Harness 桌面版（~/.dsh/profiles/desktop/cordis.patch.yml，设置了 DSH_HOME 时以其为准），以及 ChatGPT Desktop（仅做安装探测、启动和设备管理）。

可以。每个客户端的配置面板都支持手动填写 API 地址、API Key 和模型，并可读取该地址的模型列表。对于不在白名单内的地址，AI Helper 会显示目标 Origin 并要求你确认，默认要求 HTTPS，避免 Key 被误发到未授权的站点。

一键配置需要登录 Bob API 账号，并按客户端分组写入 API Key 和推荐模型：Claude Code 使用 claude-sonnet-5-5；Codex 与 ChatGPT 使用 gpt-5.6-sol；Cursor、WorkBuddy 与 Accio Work 使用 glm-5.3；DeepSeek Harness 使用国产Token计划分组的 Key，写入该 Key 下全部可对话模型，默认模型为 deepseek-v4.1-flash。如果账号下没有对应分组的 API Key，AI Helper 会自动创建一个。手动配置时可以改用任意模型。

AI Helper 只修改与接入相关的字段（API 地址、Key、模型），Claude Code、Codex 和 WorkBuddy 的其他配置会被保留；WorkBuddy 中你手动添加的其他模型不会被删除；DeepSeek Harness 只写入 aihelper-* 路由和 AIHELPER_* 密钥引用，你的自建路由、注释和官方账号路由逐字节保留。首次修改前会保存原配置快照，可在设置页一键恢复。重要配置仍建议自行备份。
