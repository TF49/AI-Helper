# Code of Conduct / 行为准则

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

本项目采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/) 作为行为准则。

## In short / 简而言之

We want Issues, pull requests and discussions to be a welcoming, harassment-free space for everyone, regardless of background or experience level.

我们希望 Issue、PR 与讨论区对所有人都友好、无骚扰，无论背景与经验如何。

Expected / 我们期望：

- be respectful and assume good faith / 尊重他人，默认善意
- give and accept constructive feedback / 提出并接受建设性意见
- focus on what is best for users and the project / 以用户和项目利益为先

Not acceptable / 不可接受：

- harassment, insults, or personal attacks / 骚扰、辱骂或人身攻击
- publishing others' private information (including API keys you find in logs or screenshots) / 公开他人隐私信息（包括在日志或截图中看到的 API Key）
- spam and off-topic advertising / 垃圾信息与无关广告

## Enforcement / 执行

Maintainers may edit or remove comments, commits, issues and other contributions that violate this code, and may temporarily or permanently block contributors who repeatedly do so.

维护者可以编辑或删除违反本准则的内容，并可临时或永久限制屡次违规者的参与。

To report a problem privately, use the [private reporting form](https://github.com/TF49/AI-Helper/security/advisories/new) and mark it as a conduct report, or contact the maintainer [@TF49](https://github.com/TF49). All reports will be handled confidentially.

如需私下反馈，可通过[私密报告表单](https://github.com/TF49/AI-Helper/security/advisories/new)提交并注明为行为准则问题，或联系维护者 [@TF49](https://github.com/TF49)。所有报告都会保密处理。
