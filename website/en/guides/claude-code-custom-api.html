How to change the API endpoint and model in Claude Code

For AI Helper v1.0.88 · Windows & macOS · Last updated 2026-11-24 · By TF49

Short answer: Claude Code reads its API settings from the env block in ~/.claude/settings.json: set ANTHROPIC_BASE_URL to the new endpoint, ANTHROPIC_AUTH_TOKEN to your API key and ANTHROPIC_MODEL to the model name, then restart claude. AI Helper — MIT-licensed and running locally — can write all three for you after a streaming test: pick the BobAPI official node, enter your API key and choose a model.

Option 1: edit settings.json by hand

Open (or create) ~/.claude/settings.json — on Windows that is C:\Users\<your-username>\.claude\settings.json — and add or update the env block:

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://bob-api.com",
    "ANTHROPIC_AUTH_TOKEN": "your-api-key",
    "ANTHROPIC_MODEL": "claude-sonnet-5-5"
  },
  "model": "claude-sonnet-5-5"
}

Save the file, then quit and run claude again. Make sure the file is still valid JSON and that you keep any other fields that were already there (such as permissions).

Option 2: switch in one step with AI Helper

  1. Launch AI Helper and open the Claude Code panel. AI Helper locates the claude CLI automatically, including installs made through Homebrew or NVM on macOS.
  2. Choose a node: the BobAPI official node (BobAPI 官方节点, https://bob-api.com/, recommended) or the TaijiAI accelerated node (TaijiAI 加速节点, https://taijiai.online/, a backup line). Then enter your API key, or sign in to a Bob API account and use one-click setup. The first time you use a hand-entered key with a node, click Confirm for this node (确认用于此节点). Keys picked from your Bob API account, and one-click setup, only work with the BobAPI official node.
  3. Choose a model from the list (for example claude-sonnet-5-5) and click Confirm and save Claude Code config (确认并保存 Claude Code 配置). AI Helper first runs a streaming connection test and only writes once the HTTP status and time to first byte look normal.
  4. When it writes, AI Helper only updates ANTHROPIC_BASE_URL, ANTHROPIC_AUTH_TOKEN and ANTHROPIC_MODEL in env, plus the top-level model; every other field in the file stays the same.
  5. Start a new claude session and the new settings take effect.

With one-click setup (which requires signing in to a Bob API account), Claude Code uses the API key from the CC-Kiro-Max group — the key group in a Bob API account reserved for Claude Code (see key groups, in Chinese). The recommended model is claude-sonnet-5-5. With manual setup you type your API key yourself, without signing in or choosing a group.

How to restore your original settings

Before AI Helper changes your Claude Code settings for the first time, it saves a snapshot (in ~/.ai-helper/reset_state.json). Use one-click restore on the Settings page to go back to exactly how things were before AI Helper touched them.

FAQ

The connection test returns 401. What does that mean?

Authentication failed. Check that ANTHROPIC_AUTH_TOKEN (or x-api-key) belongs to that API endpoint, and that the key has not expired or been disabled.

I changed the settings but Claude Code still uses the old endpoint. Why?

Check whether ANTHROPIC_BASE_URL is also set as a system environment variable, and make sure you fully exited and restarted the claude session.

AI Helper can't find the claude command. What should I do?

GUI apps on macOS don't inherit your terminal's environment variables, so AI Helper checks /opt/homebrew/bin and /usr/local/bin and searches ~/.nvm/versions/node for Claude Code installed globally with npm. If it still says the Claude CLI install path was not found, click Detect in AI Helper's path management, or select the claude executable by hand.

Will AI Helper overwrite settings.json if the file is malformed?

No. If the existing ~/.claude/settings.json can't be parsed as JSON, AI Helper stops without writing and warns that the existing Claude configuration is corrupted, so that your security rules are not lost. Fix the file format first, then save again.
