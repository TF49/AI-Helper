Claude Code 如何切换 API 地址与模型

适用于 AI Helper v1.0.88 · Windows 与 macOS · 最后更新 2026-11-22 · 作者 TF49

简短回答：Claude Code 从 ~/.claude/settings.json 的 env 字段读取 API 配置。把 ANTHROPIC_BASE_URL 设为新的 API 地址、ANTHROPIC_AUTH_TOKEN 设为对应的 API Key、ANTHROPIC_MODEL 设为模型名，然后重新启动 claude 即可切换。AI Helper 可以自动完成这三项写入，并在保存前做一次流式连通性测试。

方法一：手动修改 settings.json

打开（或新建）~/.claude/settings.json，Windows 上对应 C:\Users\你的用户名\.claude\settings.json，加入或修改 env 字段：

{
  "env": {
    "ANTHROPIC_BASE_URL": "https://你的-api-地址",
    "ANTHROPIC_AUTH_TOKEN": "你的 API Key",
    "ANTHROPIC_MODEL": "claude-sonnet-5-5"
  },
  "model": "claude-sonnet-5-5"
}

保存后退出并重新运行 claude。注意保持文件为合法 JSON，并保留文件中原有的其他字段（例如 permissions）。

方法二：用 AI Helper 一键切换

  1. 启动 AI Helper，进入 Claude Code 面板。AI Helper 会自动探测 claude CLI 的位置，包括 macOS 上通过 Homebrew 或 NVM 安装的版本。
  2. 选择预置节点或手动填写 API 地址，输入 API Key。外部地址需要确认目标 Origin，默认要求 HTTPS。
  3. 从模型列表中选择模型（例如 claude-sonnet-5-5），执行流式连通性测试，确认返回 HTTP 状态与首包时间正常。
  4. 点击「保存并应用 Claude Code 配置」。AI Helper 只更新 env 中的 ANTHROPIC_BASE_URL、ANTHROPIC_AUTH_TOKEN、ANTHROPIC_MODEL 以及顶层 model，文件中的其他字段保持不变。
  5. 重新打开 claude 会话，新配置即生效。
登录 Bob API 账号后使用「一键配置」时，Claude Code 会使用「CC-Kiro-Max」分组（Bob API 账号下 Claude Code 专用的令牌分组，分组说明）的 API Key，推荐模型为 claude-sonnet-5-5。

如何恢复原来的配置

AI Helper 首次修改 Claude Code 配置前会保存快照（位于 ~/.ai-helper/reset_state.json）。在设置页使用一键恢复，即可还原到 AI Helper 修改之前的状态。

常见问题

测试时返回 401 怎么办？

说明身份认证失败，请检查 ANTHROPIC_AUTH_TOKEN（或 x-api-key）是否与该 API 地址匹配，以及 Key 是否已过期或被禁用。

改了配置但 Claude Code 仍连旧地址？

检查系统环境变量中是否也设置了 ANTHROPIC_BASE_URL，并确认已经完全退出并重新启动了 claude 会话。
