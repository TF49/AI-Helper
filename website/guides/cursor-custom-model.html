如何给 Cursor 配置 glm-5.3 等第三方模型

适用于 AI Helper v1.0.88 · Windows 与 macOS · 最后更新 2026-11-24 · 作者 TF49

简短回答：只改 OpenAI Base URL 不够，因为 Cursor 使用 Connect-RPC / HTTP2 通信。MIT 开源的 AI Helper 在本机运行 Bridge（默认 127.0.0.1:8969），把 Cursor 请求转换后转发到你在面板中选择的 BobAPI 节点，填入 API Key 和模型后即可使用 BobAPI 上的 glm-5.3 等模型。

准备工作

  • 已安装 Cursor，并至少启动过一次。
  • Bob API 账号的 API Key（也可以在 AI Helper 中登录账号后一键配置）。
  • 已安装 AI Helper（下载地址，Windows 10/11 或 macOS 11+）。

配置步骤

  1. 打开 Cursor 面板。启动 AI Helper，首页会自动检测 Cursor 的安装路径；进入 Cursor 配置面板。
  2. 选择节点并填写 API Key。接入节点可选「BobAPI 官方节点」（https://bob-api.com/，推荐首选）或「TaijiAI 加速节点」（https://taijiai.online/，备用专线），然后输入 API Key。手动填写的 Key 首次用于某个节点时，需点击「确认用于此节点」；从 Bob API 账号选择的 Key 和一键配置只能用于 BobAPI 官方节点。
  3. 选择模型。AI Helper 会从所选节点读取模型列表，选择 glm-5.3 或其他模型；也可以手动输入模型名。
  4. 保存配置。点击「确认并保存 Cursor 配置」，连通性测试通过后，AI Helper 会把配置写入 ~/.ai-helper/cursor_config.json 并启动本地 Bridge。
  5. 接入 AI Helper。在面板的客户端状态区点击「接入 AI Helper」，修补 Cursor 客户端，使其请求发往 Bridge。
  6. 重启 Cursor。点击「重启 Cursor」，然后在 Cursor 的模型选择器中选择刚才配置的模型。

只改 Base URL 与使用 AI Helper Bridge 的区别

项目只在 Cursor 设置里改 OpenAI Base URLAI Helper 本地 Bridge
通信协议Agent 等功能仍走 Cursor 的 Connect-RPC / HTTP2Bridge 把 Cursor 请求转换为 OpenAI 兼容请求
可用模型无法完整接入第三方模型BobAPI 节点上的模型，例如 glm-5.3；支持流式响应、思考内容和图片输入
本机写入内容Cursor 设置~/.ai-helper/cursor_config.json，以及可还原的 Cursor 客户端补丁（修补前自动备份）
如果你使用 Bob API 账号登录 AI Helper 并执行「一键配置」，Cursor 会自动使用「国产Token计划」分组（Bob API 账号下国产模型专用的令牌分组，分组说明）的 API Key，推荐模型为 glm-5.3；账号下没有该分组的 Key 时会自动创建。

Bridge 支持哪些能力

  • Cursor 请求与 OpenAI 兼容请求之间的双向转换，支持流式响应。
  • 文本、思考内容（reasoning）和图片输入。
  • 向 Cursor 提供可用模型列表与默认模型。
  • 让 Cursor Agent 在当前工作区读取、搜索文件；写入、删除等操作需要先在面板中授权该工作区（授权记录在 ~/.ai-helper/agent_workspaces.json）。

关闭 AI Helper 主窗口后，它会留在系统托盘中，Bridge 继续运行；从托盘彻底退出后 Bridge 才会停止，此时 Cursor 中的第三方模型将不可用。

安全措施

Bridge 只监听本机回环地址。每条连接的第一个请求会根据对端端口找到发起连接的进程，只接受与 AI Helper 属于同一系统用户的进程，无法确认时一律拒绝；同时校验 Host、Origin 和 Content-Type。

如何还原为 Cursor 官方连接

在 Cursor 面板中点击「恢复官方连接」，或在 AI Helper 设置页使用一键恢复：Bridge 会停止，Cursor 客户端补丁会被还原。

常见问题

端口 8969 被占用怎么办？

在 Cursor 面板的「Bridge 网关端口」中改成其他空闲端口并保存，然后点击「重启 Cursor」。如果 Cursor 已接入 AI Helper，重启前会按新端口重新修补客户端。

Cursor 升级后第三方模型失效了？

Cursor 更新可能覆盖被修补的文件。打开 AI Helper 的 Cursor 面板，如果状态显示为官方直连，点击「接入 AI Helper」重新修补，再重启 Cursor。

关闭 AI Helper 窗口后，Cursor 还能用第三方模型吗？

能。关闭主窗口后 AI Helper 会留在系统托盘中，Bridge 继续运行；只有从托盘彻底退出 AI Helper，Bridge 才会停止，此时 Cursor 中的第三方模型将不可用。

Cursor Agent 修改文件时提示“该工作区尚未授权”怎么办？

Bridge 只允许 Cursor Agent 在已授权的工作区内写入或删除文件。打开 AI Helper 的 Cursor 面板，在「待授权请求」中点击「允许」后重试即可；授权记录保存在 ~/.ai-helper/agent_workspaces.json，可在「已授权工作区」中撤销。
