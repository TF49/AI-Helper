补充修复：锁定的 Tauri CLI 2.8.1 的 signer 子命令只识别旧签名环境变量；签名脚本现兼容映射并恢复原环境，检查退出码与非空签名。凭据来源库的刷新、Managed 优先判定与落盘也置于同一跨进程事务中，防止陈旧 External 快照覆盖 Managed 分类。
