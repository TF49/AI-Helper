## 本轮行为

- WorkBuddy 使用稳定顺序的 OS 文件锁和事务日志，先恢复再合并并保留未知字段；多位置失败回滚，崩溃后先恢复再接收新操作。
- Windows 会话使用用户 DPAPI；macOS/Linux 使用系统凭据服务，文件仅存随机引用。服务不可用、迁移或验证失败会阻止激活并提示重登，不退回明文或同目录密钥。
- 登录、2FA、刷新和退出受本地代次及磁盘 revision 约束；其他实例退出/换账号后，旧成功响应不能清 marker 或覆盖新会话。
- Codex 将目标和 CLI 可读凭据原子写入一个私有配置，不再为新配置改写全局 Key 环境变量，保留用户其他配置。
- 官方透明转发只允许已知 HTTPS origin；余额、Token 与日志不再按硬编码汇率展示确定货币。
- Windows ACL 仍要求当前进程用户的私有权限；此前 Actions 的 LA 别名断言错误已由同事修正，本轮增加三个平台和全编译目标检查。
