# SEC-11 / SEC-12 服务端约束（本仓库可落地部分）

这两项必须在账户/额度服务端完成。本客户端仓库只能声明契约与失败关闭行为，不能替代服务端证据。

## SEC-11 认证、会话与对象授权

服务端必须证明：

- Token 读写、改组、改状态均校验对象归属，A 不能操作 B。
- 登录、2FA flow、refresh、注销后 refresh 按已确认策略拒绝重放与旧令牌。
- 无权模型、分组、IP 策略修改被拒绝且无状态变化。

客户端已做的配合：切组不再用列表重建覆盖限额；登出阻断自动刷新并重建 CookieJar。这些不能当作对象授权已完成。

## SEC-12 额度硬限与记账

服务端必须证明：

- 余额只够一单时，多 CLI / 多节点并发请求的接受数量不超过边界。
- usage、退款、充值回调幂等，错误签名/金额无状态变化。
- 超时、跨日、重启、切组不把未决额度当可用余额释放。

客户端已做的配合：付费请求一旦派出即不得换供应商重做；生图需显式模型名；进程内整数预算预留。这些不能当作账户全局硬限已完成。

## 交付要求

验收 SEC-11-T / SEC-12-T 时提交：服务版本、隔离测试账号、脱敏请求/响应、前后余额与台账。仅客户端截图无效。
