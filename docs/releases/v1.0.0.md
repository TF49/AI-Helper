# AI Helper v1.0.0

AI Helper 首个 Windows x64 正式版本发布。

- 管理 ChatGPT/Codex 和 Claude Code 的 API 端点（Endpoint）与 API Key 配置。
- 测试 API 连通性，并从兼容的服务商拉取可用模型列表。
- 支持搜索模型列表或直接输入自定义模型 ID。

## 下载说明

- **Windows 安装包（推荐）：** `AI-Helper-v1.0.0-Windows-x64-Setup.exe`
- **Windows 便携免安装版：** `AI-Helper-v1.0.0-Windows-x64-Standalone.zip`
- **SHA-256 校验和：** `SHA256SUMS.txt`

运行要求：Windows 10/11 x64 以及 Microsoft Edge WebView2 Runtime。如果系统缺少该运行库，安装程序支持自动下载并安装（需联网）。
便携版（ZIP）配置将保存在系统的标准用户目录中。

本版本未进行代码签名，因此 Windows 可能会弹出“未知发布者”的安全提示。当前未配置自动更新，后续版本更新请前往本仓库的 Releases 页面下载。

构建验证：已通过 TypeScript 类型检查、10 项 Rust 单元测试以及 Tauri 生产环境打包构建。
