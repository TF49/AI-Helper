- 🔔 **公告弹窗偏好**：是否在重大更新时弹出公告中心。

- ✨ **极光动效开关**：工作台氛围光可按需关闭，省心也省电；  
- 🌐 **界面语言预留**：简中 · 繁中 · 英 · 法 · 俄 · 日 · 越，设置项已就位。

#### ℹ️ 关于
- 🔖 当前版本号展示；  
- 🔄 检查更新（状态形变按钮）；  
- 💬 一键打开意见反馈；  
- 🌍 外链官网 / 社区。

### 4. 📊 使用日志与用量统计：分页 · 筛选 · 聚合，消费明细一目了然 💎📈✨

全新 [`UsageLogsPanel`](file:///e:/Developer%20Tool/AI%20Helper/src/components/account/UsageLogsPanel.tsx) + 后端 `get_user_usage_logs` / `get_user_usage_stat`！📋

- ⏱️ **时间预设**：今天 · 近 7 天 · 近 30 天 · 全部；  
- 🔍 **模型名 / Token 名** 防抖搜索（`CircleToSearchBar` 同款体验基因）；  
- 📑 **分页列表**：模型、Key、分组、Prompt / Completion Tokens、耗时、额度；  
- 📈 **聚合统计卡片**：总请求、总额度、Token 用量、平均耗时，一眼看懂消费节奏！

| 字段亮点 | 说明 |
|---|---|
| 🏷️ `token_name` / `model_name` | 哪把 Key、哪个模型在烧额度 |
| 🔢 `prompt_tokens` / `completion_tokens` | 输入输出 Token 明细 |
| 💰 `quota` | 本次消耗额度 |
| ⏳ `use_time` | 请求耗时，方便排查慢请求 |
| 📦 `group` | 所属通道分组 |
