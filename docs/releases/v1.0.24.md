## 🚀 详细更新亮点

### 1. 🎨 官方原生品牌视觉体系全面重构 (Official Brand Icons & Visual Identity Redesign)

- 🧐 **告别通用抽象图标，迈向专业原生审美**：
  - 在以往版本中，界面大量使用了通用的 Lucide 几何图标（如用通用机器人小图标 `Bot` 代表 ChatGPT/Codex，用小星星 `Sparkles` 代表 Claude）🤖✨；
  - 这种设计在功能上虽然可用，但在视觉识别度、品牌专业感与现代感上略显简陋与抽象，无法直观传递顶级大模型工具的官方质感 📉；
- 🌌 **打造高保真原生品牌图标库 (`src/components/BrandIcons.tsx`)**：
  - 本次更新重磅引入了工业级精细度的 SVG 矢量图标组件库，完整封装了原生品牌资产 💎：
    - 🌀 **`OpenAIIcon` (及别名 `ChatGPTIcon`, `CodexIcon`)**：高精度还原 OpenAI 官方标志性螺旋几何漩涡矢量设计，数学比例严丝合缝，支持跟随文字上下文自适应 `currentColor` 与自定义尺寸 🌀⚡；
    - ☀️ **`ClaudeIcon`**：高精度还原 Anthropic Claude 官方经典的太阳花辐射星芒几何矢量，线条层次细腻丰富，原生支持 Anthropic 标志性的暖橙棕专属品牌色 (`#D97757`) 与暗黑主题智能变色 🍁✨；
    - 🛡️ **`BrandLogo`**：深度封装 AI Helper 官方高清光感 App 图标 (`/logo.png`)，集成防拖拽、自适应缩放与高清阴影渲染，塑造独一无二的工具品牌心智 🏆；
- 🎯 **八大核心交互场景全量换装覆盖**：
  - 1️⃣ **应用主标题栏 (TitleBar)**：彻底淘汰原先随 Tab 切换而变动的通用小图标，升级为常驻且辨识度极高的 `BrandLogo` 品牌徽标，搭配微光投影，开门见山立显高阶气质 🪟👑；
  - 2️⃣ **左侧/顶部 Tab 导航栏**：ChatGPT 切换项全面换装为精致的 `OpenAIIcon`，Claude 切换项换装为大气的 `ClaudeIcon`，选中与悬浮反馈一目了然 🧭🔖；
  - 3️⃣ **ChatGPT 核心配置面板 (`ChatGPTPanel.tsx`)**：面板 Header 处徽章升级为官方 `OpenAIIcon` 搭配湛蓝微光卡片，科技感扑面而来 📘💙；
  - 4️⃣ **Claude 核心配置面板 (`ClaudePanel.tsx`)**：面板 Header 处徽章升级为官方 `ClaudeIcon` 搭配优雅紫罗兰光环，浑然天成 🔮💜；
  - 5️⃣ **应用路径主管理面板 (`AppPathsPanel.tsx`)**：Claude Code CLI 与 ChatGPT 客户端状态卡片头部全面升级为官方原生徽章，状态指示更加醒目 🛠️💡；
  - 6️⃣ **初始化与环境体检向导 (`InitializationModal.tsx`)**：环境检测清单、配置卡片、协议切换等多个节点全面拥抱官方图标，新手引导体验更加专业亲切 🐣📋；
  - 7️⃣ **快捷小工具箱 (`QuickToolsModal.tsx`)**：模型测试与快速转换的协议切换胶囊（Pills）全面内置官方 Logo，轻盈灵动 🧰💊；
  - 8️⃣ **终端集成与进程控制模态框 (`TerminalTestModal.tsx`)**：「启动/重启 ChatGPT 客户端」与「启动/重启 Claude Code 终端」操作按钮嵌入原生品牌微标，按键意图清晰直观 💻⚡！

### 2. 📜 应用路径面板视口防截断与智能平滑对焦 (Smart Viewport Auto-Focus & Smooth Scrolling)

针对用户在管理面板中查阅、复制 CLI 手动安装与升级命令时遇到的交互瓶颈，进行了深度重构与视口动效升级 🌊🚀：

- 😫 **直击以往痛点：抽屉展开被截断、手动滑轮找命令**：
  - 在窗口高度适中或屏幕分辨率有限时，点击「手动安装 / 更新」或「展开命令抽屉」后，抽屉由于高度较大，往往会自动延伸到视口下方被边缘截断 🙈；
  - 开发者不得不多次手动滚动鼠标滚轮才能看到底部的完整 `npm` 命令或 PowerShell 脚本，打断了快速复制的连贯心流 💢；
- 🎯 **智能视口平滑自动居中对焦 (`scrollIntoView`)**：
  - 在 `AppPathsPanel` 中引入精确的 React 状态监听与引用锚点系统 (`topGuideRef`, `claudeDrawerRef`, `codexDrawerRef`) ⚓；
  - 运用 `useEffect` 配合浏览器的 `requestAnimationFrame` 驱动帧：
    - 当开发者点击展开 **Claude Code 命令抽屉** 时，面板自动平滑向下滚动至抽屉完整呈现的最佳视野 🟣👇；
    - 当开发者点击展开 **Codex CLI 命令抽屉** 时，面板精准捕捉视口位置并以顺滑缓动效果对齐 🔵👇；
    - 当开发者切换顶部的 **CLI 手动安装命令中心** 时，自动平滑回滚至顶部指引区域 🌟👆；
    - 真正做到**“所点即所见，展开即对齐”**，双手无需离开键盘或反复滑动滚轮 🪄🤩！
- 🛡️ **弹性布局防挤压与高度自适应 (`min-h-fit` & `flex-shrink-0`)**：
  - 针对外层 Flex 弹性容器在内容动态撑大时可能产生的卡片挤压变形隐患，为所有的 `SpotlightCard` 及抽屉外层包裹容器全量补齐 `min-h-fit` 与 `flex-shrink-0` 弹性锁 🔒；
  - 无论用户如何频繁展开/收起多个长抽屉，卡片与排版始终保持最完美的工业级形态，彻底杜绝内容被压扁或溢出重叠 🧱💪；
- 🌊 **全容器原生丝滑滚动 (`scroll-smooth`)**：
  - 外层主滚动视口加入原生 `scroll-smooth` 流体动效类，配合微调后的内边距 (`pb-2`)，滚动过程无任何卡顿掉帧，手感如同黄油般细腻顺滑 🧈✨。
