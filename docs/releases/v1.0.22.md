## 🚀 详细更新亮点

### 1. 🛠️ CLI 手动安装与版本更新中心 (参考 cc-switch 规范)

针对刚接触 **Claude Code CLI** 与 **OpenAI Codex CLI** 的开发者在环境初始化、镜像源加速、版本升级等环节的常见痛点，本项目深度融合并对齐了业内著名的 `cc-switch` 开源项目安装规范，重磅推出了原生的 **「CLI 手动安装与版本更新命令中心」** 💎⚡：

- 📦 **全矩阵安装渠道覆盖 (Multi-channel Package Management)**：
  - ⚡ **npm 官方最新版 (`@latest`)**：
    - `npm install -g @anthropic-ai/claude-code@latest` 🦄
    - `npm install -g @openai/codex@latest` 🤖
    - 快速获取上游官方最新发布特性与安全补丁；
  - 🚀 **国内 npmmirror 镜像源加速**：
    - 专门提供带 `--registry=https://registry.npmmirror.com` 的淘宝/npmmirror 国内极速源命令，彻底击碎中国大陆网络环境下的下载超时、连接断开与假死难题 🚄🌏；
  - 🦄 **pnpm 高速全局管理**：
    - 支持通过 `pnpm add -g ...` 进行现代化轻量级依赖复用管理；
  - 🪟 **Windows 原生免全局 Node 脚本**：
    - 完整支持 Anthropic 官方推荐的 PowerShell 独立原生脚本：  
      `powershell -c "irm https://claude.ai/install.ps1 | iex"` 💻
  - 🍎 **Unix / macOS / Linux 原生与 Homebrew**：
    - 支持官方 Shell 脚本 `curl -fsSL https://claude.ai/install.sh | bash` 与 macOS Homebrew `brew install codex` 🍏；
- 🖥️ **原生拉起独立外部终端一键运行 (`execute_in_terminal`)**：
  - 在 Rust 后端底层新增 `process_manager::execute_in_terminal` 核心指令，配合 Windows 系统的 `cmd.exe /c start "..." cmd.exe /k <command>` 架构 ⚡；
  - 开发者无需手动打开系统控制台并粘贴，只需在界面点击 **「在终端运行」** 按钮，系统即刻在桌面上拉起全新的独立 CMD 终端窗口并自动运行命令，带 `/k` 交互参数确保命令执行完毕后窗口不自动关闭，方便实时查看安装日志与错误输出 🎯；
- 📋 **毫秒级一键复制与微交互反馈**：
  - 每一项命令均配备独立复制按钮，点击后立即呈现绿色勾选徽章 (`Check`) 并联动触发全应用统一的优雅 Toast 浮动提示 💬✨；
- 🩺 **前置 Node.js 运行环境体检诊断 (Node.js & npm Diagnostic)**：
  - 特设独立的「运行环境检测」选项卡，内置 `node -v`（要求 Node.js >= 18.0.0 LTS）与 `npm -v` 快捷核验命令，同样支持一键复制与在终端一键测试；
  - 贴心附带 **Node.js 官方网站一键直达跳转外链**，无环境开发者可秒级直达下载 🌐；
- 📂 **主卡片内嵌抽屉交互 (Card-level Inline Drawer)**：
  - 不仅在顶部全局提供总览中心，还在 Claude Code CLI 与 Codex CLI 每一张专属路径配置卡片中直接内置了 **「安装命令」抽屉开关** 🗂️；
  - 抽屉内无缝支持快速切换安装源与在终端运行，并在执行后可立即在当前卡片一键点击 **「探测就绪」**，原地刷新本地识别状态，实现极致顺滑的操作闭环 🔄！

### 2. 🎯 彻底终结虚假路径：智能环境仲裁与精准状态感知 (Intelligent Environment Sensing)

- 🚨 **痛点根除**：
  - 在旧版逻辑中，即使开发者电脑上完全没有安装 Claude CLI 或 Codex CLI，界面依然会机械式地展示 `%USERPROFILE%/.claude/settings.json` 或 `%USERPROFILE%/.codex/config.toml` 路径，并提示「待初始化」，导致开发者误以为当前已经就绪、只是缺少配置文件，产生了强烈的认知困扰 🤦‍♂️；
- 🛡️ **后端四维严谨智能仲裁算法**：
  - 在 Rust 核心层（`src-tauri/src/claude.rs` 与 `src-tauri/src/codex.rs`）重构 `ClaudeConfig` 与 `CodexConfig` 数据模型，全面引入 `is_installed: bool` 与 `app_path: Option<String>` 字段 🧩；
  - 进行全方位的四维联动检测：
    1. 📂 检查配置文件是否真实物理存在 (`config_exists`)；
    2. 🔍 检索全局 CLI 可执行程序（`detect_claude_cli_path`、`detect_codex_cli_path`）；
    3. 💻 检索 WindowsApps 与 Win32 ChatGPT 桌面客户端（`detect_chatgpt_client_path`）；
    4. 💾 校验用户在系统设置中持久化保存的手动自定义路径；
  - **重要原则**：仅当上述四维条件之一确认命中时，才判定应用已安装并输出有效路径；**若完全未安装，则坚决置空 `config_path`**，绝不输出任何误导性的虚假路径 🚫虚假！
- 🏷️ **前端状态徽章 (`StatusBadge`) 升级为清晰三态指示**：
  - 🟢 **已检测到配置 (emerald)**：环境已就绪且配置文件完全合法存在，安心使用；
  - 🟡 **待初始化 (amber)**：已检测到 CLI 或客户端运行环境，但当前尚未生成配置文件，提示开发者前往保存初始化；
  - 🔴 **未检测到环境 (rose)**：系统完全未检索到任何运行程序与配置文件，路径栏明确提示 `未检测到安装或配置文件`，并以醒目的玫瑰红胶囊警示开发者需先安装 Agent 🚨！

### 3. 🧭 开机与重置初始化向导 2.0 (Initialization Pipeline 2.0)

针对全新设备冷启动与初始化流程，对 `InitializationModal` 进行了多项人性化重构与容错提升 🌈：

- 📡 **雷达实时扫描精准感知**：
  - 环节 2（本机环境深度扫描）全面接入多 Agent 智能安装识别，扫描日志能够精确定位到每个 Agent 的物理运行入口（如 `AppData\Roaming\npm\claude.cmd` 等）或明确标记未安装 🔎；
  - 根据本地实际安装情况，智能提示「已准确定位 2 处本地 Agent」或「已检测到 Claude Code 环境（ChatGPT / Codex 未安装）」，告别死板文案 💡；
- 🛠️ **未安装场景下的优雅回退引导**：
  - 当在纯净机器上检测到未安装任何 Agent 时，向导不再抛出生硬死板的错误阻断流程，而是弹出一目了然的 **快速安装指引卡片**，将 Claude 与 Codex 的最新 npm 安装命令直接附在报错卡片中，支持一键点击复制 📋；
- ⚡ **新增「跳过检测，强制预配置」高级模式**：
  - 专为有提前部署需求的高级开发者打造！即便当前电脑尚未安装 CLI，也可以点击 **「跳过检测，强制预配置」** 按钮绕过环境拦截，直接进入环节 3；
  - 系统将载入标准配置结构模板，保存后即可提前生成好规范的 `settings.json` 或 `config.toml`，后续安装 CLI 后即可开箱即用 🪄；
- 🗂️ **解析与展示环节动态适配**：
  - 环节 3 根据是否已安装该 Agent，在选项卡按钮右上角智能标注 **「未安装」** 灰度标签；
  - 进度指示器从原来的死板文案自适应变更为「装载本地配置文件二进制流」或「载入默认配置规范模板」，逻辑极其严谨 📊！

### 4. 📋 全局文本无障碍划选与自由复制 (Seamless Text Selection UX)

在过往版本中，由于桌面端根节点与部分模态框套用了 CSS 类名 `select-none`，导致用户在遇到错误、测试网络连通性或查看长路径时无法通过光标选中文字，无法直接复制排错信息 😫。

- 🔓 **全面解放文本选区**：
  - 在核心样式表 `src/index.css` 中为 `body` 显式声明 `user-select: text` 与 `-webkit-user-select: text` 🖋️；
  - 逐一排查并彻底移除了 `App.tsx` 根容器、`ForceUpdateModal.tsx` 强制升级模态框、`TerminalTestModal.tsx` 终端测试黑盒弹窗等组件根部滥用的 `select-none` 限制类名 🪓；
  - 开发者现在可以自由划选、双击选中并右键/快捷键复制：
    - 📟 终端测试返回的全部实时输出与错误堆栈；
    - 🌐 接口 Base URL 与代理服务地址；
    - 🔑 认证密钥 API Key 隐藏前后的字符；
    - 📁 系统盘深层文件路径与模型代号；
  - 真正做到了让开发者在桌面端拥有同原生 Web 一样丝滑自如的复制粘贴体验 🎉！
