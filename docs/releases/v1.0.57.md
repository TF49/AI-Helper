#### 🛡️ 3. Rust 底层 401 会话凭据透明重试机制 ([`src-tauri/src/auth.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/auth.rs)) 🔒
- 🚀 **痛点解决**：以往桌面端长时间在后台挂起或休眠后，服务端的 `access_token` 可能过期，导致额度查询报 401 错误；
- 🛡️ **自愈链路**：在 Rust 核心函数 `get_user_wallet()` 中，若捕获到 `StatusCode::UNAUTHORIZED`，底层会自动唤起 `refresh_session()` 刷新凭证，并透明发起二次重试：
  ```rust
  if resp.status() == reqwest::StatusCode::UNAUTHORIZED {
      if let Ok(refreshed) = refresh_session().await {
          token = refreshed.access_token;
          // 自动使用新 token 再次发起请求，用户完全无感！
      }
  }
  ```
  保证账号资产数据的长效持久可用，真正做到零弹窗打扰！💎

以往开发者若想为某个 AI 工具（如 Claude Code 或 Codex）更换通信通道或升迁到 VIP 高可用通道，通常需要：

4. 复制长串密钥；
5. 打开本地配置文件粘贴覆盖；
6. 重启终端或 Agent CLI 进程。

**繁琐的操作现在彻底成为历史！AI Helper v1.0.57 首创「零感通道分组秒级热切换」！** 🎉🎉

#### 🏎️ 1. 毫秒级即时生效：原理与极客体验 ⚡
- 💡 **核心原理**：API Key 的明文字符串（`sk-xxx`）在本地保持完全不变，通过调用底层 API 接口（`PUT /api/token/`）直接在云端重新绑定该 Key 所属的通道分组路由规则；
- 🎯 **零重启、零改动**：本地已经配置运行中的 **Claude Code CLI**、**Codex CLI**、**ChatGPT**、**WorkBuddy** 或 **Accio Work** 完全无需重启或重写配置，当下一次发起对话请求时，网关直接按新分组进行负载均衡与分流！💨

#### 🎛️ 2. 全方位无死角的切流触发入口 ([`src/components/ChannelGroupMonitor.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChannelGroupMonitor.tsx)) 🖱️
- 📊 **指标卡片一键直切**：当你在监控大盘中临时点击预览某个非当前绑定的分组时，头部操作栏直接提供 **「⚡ 切为此组」** 按钮；
- 📂 **分组抽屉全列表快速切换**：在展开的全量分组列表中，每个非当前绑定的分组卡片均提供闪电图标切换按钮；
- ⚖️ **多通道对比弹窗直接应用**：在通道健康度对比面板中，选中最满意的低延迟通道，直接一键切换！

#### 🤖 3. 跨工具多 Agent 一键协同联动 🌐
- 在确认切换弹窗中，支持勾选 **「同时将此生效 Key 同步至全部 4 大本地 Agent (Codex, Claude, Workbuddy, Accio)」**；
- 一键确认后，Rust 后端不仅更新云端路由，还会将对应 Key 的明文写入本地全部 4 个工具的配置文件中，并广播全局事件，真正实现“一次切换，全家桶生效”！🚀
