### 1. 🎨 四大 Agent 面板底部导航栏全面重构（统一优化设计）

本次重构涵盖 **ChatGPT / Codex CLI**、**Claude Code CLI**、**WorkBuddy AI**、**Accio Work** 四大配置面板，统一底部操作区域的交互设计与视觉规范：

- 🔄 **「重新配置向导」辅助按钮**：左下角统一放置重置向导入口，随时从第 0 步重新开始；
- 💾 **主保存按钮统一加宽**（`min-w-[210px]`），确保按钮文字完整展示、点击区域充裕；
- 📊 **「步骤 X / N」进度指示器**：向导模式下在底部导航中心实时显示当前进度；
- 🎨 **统一去除过度拉伸与动态光效**，整体视觉更简洁内敛，减少视觉干扰；
- 🔵 **品牌色贯穿**：所有操作按钮统一使用蓝色（`blue-600`）主题色，与 OpenAI 品牌强关联。

#### 🟣 `ClaudePanel` · Claude Code CLI 配置面板

### 4. ⚡ 更新源架构优化：本站自托管直链优先（updater.rs）

- 🚀 **新增本站自托管更新元数据接口**（`https://helper.bob-api.com/downloads/latest.json`）：
  - 第一优先级：直接拉取本站 `updater.json`，国内用户**零代理直连**，彻底规避 GitHub `api.github.com` 在国内的不稳定问题；
  - ✅ 成功即返回，秒级完成版本检测；
  - ⚠️ 失败降级：依次尝试 ghfast.top 镜像 → gh-proxy → ghfast → ghproxy.net → 官方 GitHub 原始地址；
- 🔗 **新增本站安装包直链**：
  - 检测到有效代理（VPN 已开启）时，官方 GitHub 链接升为第二位；
  - 否则，国内镜像路由优先，最大化下载成功率；
- 🌐 **官网落地页（`website/index.html`）同步更新**：
  - 主下载按钮指向 `https://helper.bob-api.com/downloads/AI-Helper-v1.0.50-Windows-x64-Setup.exe`；
  - 提供本站直链 + 国内加速镜像（`ghfast.top`）双链路；
  - 国内镜像 ZIP 绿色通道同步更新；
- 📜 **版本检测逻辑优化（website/assets/script.js）**：
  - 改为只读同源 `version.json`，不再向 `api.github.com` / `raw.githubusercontent.com` 发起跨域同步请求（国内不稳定），避免被 GitHub 直链覆盖本站地址；
  - 同源请求失败时，保留 `CURRENT_VERSION` 静态兜底，确保下载链接始终有效。
