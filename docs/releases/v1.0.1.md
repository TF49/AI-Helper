# AI Helper v1.0.1

**发布日期**: 2026-09-10

## 🐛 Bug 修复

### 网络检测误报修复
- **问题**: VPN 关闭时，网络检测仍然显示 bob-api.com "可用"（误报）
- **原因**: 使用 TCP 连接检测，受 DNS 缓存影响导致误判
- **修复**: 改用真实的 HTTPS GET 请求验证网络可达性
- **影响**: 现在能准确反映用户是否能真正访问 bob-api.com API

**技术细节**:
- 将 `TcpStream::connect("bob-api.com:443")` 替换为 `reqwest::get("https://bob-api.com/")`
- 验证 HTTP 状态码（仅 2xx 状态码返回"可达"）
- 保持 5 秒超时不变
- 保持前端接口兼容性
