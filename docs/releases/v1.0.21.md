## 🚀 详细更新亮点

### 1. 🎨 全新品牌超级符号：双核极光莫比乌斯环 (Brand Identity 2.0)

为了让 **AI Helper** 在开发者的桌面与任务栏中更具辨识度与极客科技质感，本版本正式确立了全新的品牌视觉语言：

- ♾️ **双核交融与数据无限循环（Infinity Metaphor）**：
  - 以经典的莫比乌斯带（Moebius Strip）为几何骨架，左侧注入代表 **OpenAI / ChatGPT / Codex** 的深邃电光青蓝（Electric Cyan），右侧注入代表 **Anthropic / Claude** 的琥珀紫金（Violet Amber）；
  - 两股能量流在中心交织流动、永续闭环，象征着 AI Helper 作为双核主流 Agent 统一调配中枢的底层哲学。
- 🌈 **全场景品牌资产库覆盖**：
  - 🖼️ **`public/logo.png`**：512×512 纯透明莫比乌斯环徽标，轻量优雅，专供前端界面与窗口标题栏使用；
  - 🖼️ **`public/brand-logo.png`**：1024×1024 高清透明底品牌标（深蓝品牌字），完美适配浅色网页与白底文档；
  - 🖼️ **`public/brand-logo-darkmode.png`**：1024×1024 高清透明底夜光版（纯白高亮字），在 GitHub 暗黑主题与深色关于界面下对比度拉满；
  - 🖼️ **`app-icon-squircle.png`**：带有深邃极光蓝黑质感与悬浮微阴影的 macOS / Fluent Squircle 卡片底座版。

### 2. 💎 工业级抗锯齿算法与全平台桌面图标库编译 (App Icons 2.0)

针对桌面应用在不同缩放比（100%、125%、150%、200% DPI）和极端小尺寸（16×16、32×32）下的严苛展示要求，进行了深度重构与编译：

- 🧪 **高精度无损白底消除算法（Color De-multiplication）**：
  - 舍弃了粗暴的硬边魔棒抠图，采用数学级色彩反向消解算法恢复 Alpha 通道；
  - 完整保留了莫比乌斯环边缘的高清抗锯齿过渡与柔和外发光，**深浅色背景下绝无廉价白边与毛刺噪点**。
- 📐 **专业应用图标留白规范（Safe Margin）**：
  - 严格剔除图标下方在小尺寸下会糊成团的细碎文字，仅保留核心莫比乌斯主体；
  - 水平留出约 7% 的安全呼吸边距，图标在 Windows 任务栏和 macOS Dock 栏中视觉饱满而不拥挤。
- 📦 **Tauri 原生编译多尺寸全量替换**：
  - 🪟 **Windows**：自动生成聚合了 16/24/32/48/64/128/256 像素图层的 `icon.ico`、`StoreLogo.png` 以及完整的 `Square*Logo.png` 矩阵；
  - 🍎 **macOS**：自动生成支持 Retina 视网膜屏的高清 `icon.icns`；
  - 🌐 **Web 与托盘**：同步更新 `public/favicon.ico`，保持整个软件生态各处视觉体验高度统一。

### 4. ⚙️ 版本发布与工程脚本六合一自动化 (Automation & DX)

针对日常版本递增与发版流程，对自动化脚本体系进行了关键扩展：

- 🔄 **`scripts/bump-version.ps1` 升级为六合一联动引擎**：

  - 全面理顺了 Release 动态徽章与 GitHub API 之间的实时轮询逻辑，发版后徽章全自动同步变更为最新版本。
