# AI Helper v1.0.14

**发布日期**: 2026-09-24

AI Helper v1.0.14 是一次具有里程碑意义的**全方位品牌重塑**与**桌面工作台双栏架构革命**版本。本版本正式将软件由原名 *BobAPI Tool* 全面更名为 **AI Helper**，并针对桌面端大屏视窗进行了根本性的交互与布局变革——彻底抛弃以往传统小窗口的上下单列挤压式堆叠，全面重构为**左侧固定导航侧边栏 + 右侧宽阔配置展台的双栏桌面工作台（Sidebar + Canvas）**。同时，本次更新对 ChatGPT (Codex) 与 Claude Code 两个核心配置面板进行了 2×2 响应式网格升级，内置常用热门模型快捷推荐芯片，重构了具备路径一键复制与快速重检能力的 StatusBadge 2.0，并完成了全链路工程构建、自动更新渠道与脚本体系的品牌同步升级。

---

### 2. 桌面双栏工作台架构重塑（Modern Split Workbench Layout）
摒弃了此前窗口内元素全部垂直单列堆叠的设计，全面引入面向桌面生产力的专业双栏工作台格局：
- **左侧功能导航侧边栏（Navigation Sidebar，`w-64`）**：
  - **配置目标（Targets）**：直观展示 ChatGPT (Codex) 与 Claude Code 两个专属 Agent Tab 入口。卡片内置定制图标、状态高亮边框、协议标签说明（OpenAI Protocol / Anthropic Protocol）与动态悬停过渡动效。
  - **实用工具与环境诊断归拢**：将此前占据标题栏空间的“环境初始化向导”与“快速诊断与工具箱”收纳至侧边栏专属工具区，操作逻辑更清晰整洁。
  - **侧边栏底部系统状态卡片**：
    - 嵌入网络连通性状态卡片，实时显示心跳连通状态（带动态扩散呼吸光晕）及一键重新检测按钮。
    - 嵌入 Tauri Engine 桌面运行状态，直接提供手动一键“检查更新”入口，检查中伴随旋转动效反馈。
- **右侧宽阔主工作台内容区（Main Canvas）**：
  - 采用 `max-w-6xl w-full mx-auto` 视口规范，充分利用大屏幕与全屏空间，左右两端自适应舒展。
  - 接入 `AnimatePresence` 与平滑位移动效，在 ChatGPT 与 Claude 配置面板切换时提供丝滑流畅的微动效切换。

### 3. 配置面板 2×2 响应式双列栅格化与热门模型快捷芯片（Dual-Column Grid & Quick Models）
在 [ChatGPTPanel.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChatGPTPanel.tsx) 与 [ClaudePanel.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/ClaudePanel.tsx) 中对内容组织结构进行了重构升级：
- **面板顶栏信息概览与快速重载**：
  - 每个面板顶部新增专属图标、配置标题、协议徽章与功能简介。
  - 新增醒目的“重新载入”快捷按钮，随时同步磁盘上的最新配置文件变更。
- **2×2 响应式双列栅格布局**：
  - **左列（基础设施与网络）**：
    - **API 服务网关节点卡片**：聚合节点网络路线选择。
    - **本地配置文件管理卡片**：展示对应本地路径（如 `~/.codex/config.toml` 或 `~/.claude.json`），提供未检测配置时的黄色警示与智能创建提醒。
  - **右列（凭据与模型）**：
    - **API Key 认证凭证卡片**：安全输入与掩码切换。
    - **测试模型卡片**：支持模型下拉自动补全、在线刷新与手动输入。
- **新增常用热门模型推荐芯片（Quick Model Chips）**：
  - **ChatGPT (Codex) 面板**：内置 `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`, `chatgpt-4o-latest` 快捷芯片。
  - **Claude Code 面板**：内置 `claude-3-7-sonnet-20250219`, `claude-3-5-sonnet-20241022`, `claude-3-5-haiku-20241022`, `claude-3-opus-20240229` 快捷芯片。
  - 点击任何芯片即可一键自动填充模型输入框，且当前已选模型芯片享有高亮激活态样式，大幅提升输入效率。

### 4. 配置文件状态徽章组件全新升级（StatusBadge 2.0）
对 [StatusBadge.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/StatusBadge.tsx) 进行了重构，从简单的单行指示升级为专业卡片：
- **视觉风格与主题色彩**：
  - 引入高辨识度 `FileCode` 图标卡片背景，并跟随面板主题自适应支持 `blue` 与 `purple` 强调色。
  - 路径文本采用等宽字体（`font-mono`），支持单行省略、鼠标悬浮 Tooltip 以及全局选中。
- **清晰的状态检测标签**：
  - 当文件存在时显示翠绿色的 `CheckCircle2`“已检测到配置”；
  - 当文件未初始化时显示醒目的琥珀色 `AlertCircle`“待初始化”。
- **增强交互功能**：
  - **一键复制完整路径**：内置剪贴板复制按钮，点击后触发绿勾微动效并弹出全局 Toast 提示。
  - **重新检测支持**：新增刷新按钮，直接调用传入的 `onReload` 钩子重新校验本地文件状态。
