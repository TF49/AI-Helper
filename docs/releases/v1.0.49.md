AI Helper v1.0.49 重磅发布啦！🎉🥳🚀✨

在过去的版本中，我们解决了多 Agent 配置统一管理、本地 Bridge 网关转译和进程树热重启等痛点。然而在实际 AI 编程与日常开发过程中，开发者经常遇到**「配了 Key 却超时报错」**、**「不清楚当前通道是否支持 Codex / Claude 流式」**以及**「无法直观了解上游链路质量与波动」**等困扰。

在本次 **v1.0.49** 中，AI Helper 带来了全新的**「通道分组智能检测与健康稳定性监控」体系**！结合 Rust 高并发异步遥测接口与现代前端可视化图表，让每一条通道的可用率、响应时延与历史健康波动一览无余，并为不同 Agent 智能匹配最优通道，告别 400/404 错误与超时中断！🌟💎

---

## 🌟 核心升级四大亮点 💡✨

### 1. 📊 通道分组智能检测与稳定性雷达 (`ChannelGroupMonitor`)
- ⏱️ **近 1h / 3h / 6h 多维度可用率与时延统计**：
  - 自动聚合调用成功率（Success Rate）、平均响应耗时（TTFT Latency）、有效请求量与熔断异常数；
  - 90 秒后台自动静默轮询更新，无感保持数据鲜活；
- 🎯 **四大 Agent 专属通道路由规则与避坑指南**：
  - 🟢 **OpenAI / Codex CLI**：深度依赖高并发流式代码补全与 Codex 专属模型，智能推荐 `codex`、`svip-codex` 专属通道分组；
  - 🟣 **Claude Code CLI**：深度依赖 Anthropic 原生流式、Extended Thinking 思考链与 Prompt Caching 特性，自动推荐匹配 `claude`、`kiro` 专属分组，规避普通分组报 400/404 错误；
  - 🟩 **WorkBuddy AI**：提供多模型聚合通道推荐，确保异构模型（DeepSeek、Claude、GPT-4o）全量覆盖与配额充沛；
  - 🟠 **Accio Work**：企业级长链路 Bridge 桥接推荐高稳定性分组，保障长时间工作流不中断；
- 🔍 **智能搜索、多维排序与对比抽屉**：
  - 支持按通道名称实时拼音与关键词模糊检索；
  - 支持按成功率最高、延迟最低、请求量最多排序；
  - 内置横向对比抽屉，多分组性能并排横评，一键秒切绑定！

---

### 2. 📈 三大形态健康遥测图表 (`HealthTrendVisualizer`)
- 🟩 **连续分段健康条 (Ribbon 模式，默认推荐)**：
  - 借鉴 GitHub Status / Cloudflare 官方设计，连续呈现 5 分钟时间桶状态；
  - 鼠标悬浮毫秒级呈现桶内成功率、时延与请求明细；
- 🌊 **平滑贝塞尔波形曲线 (Area 模式)**：
  - 超轻通透渐变波形动画，直观反映网络抖动与波峰波谷，动态渲染呼吸光晕；
- 📊 **宽幅时间遥测柱 (Bar 模式)**：
  - 高密度时间分布柱状图，直观感知高并发流量吞吐与负载健康度；
- 💾 **用户视图偏好自动持久化**：
  - 记住用户的图表形态选择，下次打开保持习惯。

---

### 3. 📁 配置文件原生路径快速直达 (`ConfigPathBar`)
- 📋 **一键剪贴板复制绝对路径**：
  - 快捷复制目标 Agent 配置文件路径，便于脚本编写与手动备份；
- ↗️ **系统原生编辑器秒级调阅**：
  - 默认编辑器 ➔ 系统记事本 ➔ 资源管理器目录定位三级智能降级；
  - 真实修改配置文件后，直观反馈文件就绪状态与绿/黄健康指示点。

---

### 4. 🌐 官网落地页重磅集成 React-Bits + GSAP
- 💎 **React-Bits 科技美学组件**：
  - **SpotlightCard**：随鼠标光标动态漫射径向高光；
  - **ShinyText**：金属流动晶体光泽文字动画；
  - **DecryptedText**：高科技字符解码/解密动效，动态逐字解密通道状态与避坑规则；
- 🎬 **GSAP 物理动效交互**：
  - 4 大 Agent 分组标签平滑切换；
  - 遥测指标数字动态滚动递增（0% ➔ 99.9%，0ms ➔ 78ms）；
  - 连续分段健康条逐级级联点亮；
  - 刷新按钮 360° 物理弹性旋转；
  - 全面修复 Hero 区域按钮文本编码乱码，版本全链路升级至 `v1.0.49`。
