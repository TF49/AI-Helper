# AI Helper v1.0.17

## What's Changed

### 🐛 修复

- **配置文件健壮性增强**：修复了 Claude Code (`settings.json`) 和 Codex (`config.toml`) 配置文件在以下异常情况下的解析崩溃问题：
  - 文件内容为空字符串或纯空白字符（空格/换行/制表符）
  - 文件内容为格式错误的 JSON / TOML，现在会优雅降级并使用默认配置，同时输出警告日志，而不是直接抛出错误

### ♻️ 重构

- **`claude.rs`**：将配置读取逻辑拆分为纯函数 `parse_claude_content` 和 `prepare_claude_json`，使业务逻辑与 I/O 解耦，便于单元测试
- **`codex.rs`**：将配置读取逻辑拆分为纯函数 `parse_codex_content` 和 `prepare_codex_doc`，同样实现逻辑与 I/O 分离

### ✅ 测试

- **`claude.rs` 单元测试**：新增 6 个单元测试，覆盖空内容、纯空白、格式错误 JSON、正常 JSON 的解析，以及写入时对空内容和损坏内容的处理
- **`codex.rs` 单元测试**：新增 6 个单元测试，覆盖空内容、纯空白、格式错误 TOML、正常 TOML 的解析，以及 `prepare_codex_doc` 对空内容和损坏内容的处理

### 🎨 界面优化

- **初始化弹窗（`InitializationModal`）**：优化了配置文件扫描步骤的状态提示文案，细化了以下状态区分：
  - 扫描出错时显示「检索失败」
  - 扫描完成但配置文件不存在时显示「配置文件待初始化」（原先一律显示「正在检索磁盘路径...」）
  - 适用于 ChatGPT (Codex) 和 Claude Code 两项扫描步骤
