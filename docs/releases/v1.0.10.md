# AI Helper v1.0.10

**发布日期**: 2026-09-24

AI Helper v1.0.10 带来了重量级的**软件启动初始化功能模块**，以高颜值弹窗配合**竖直向下动态进度条**呈现，构建起从本机网络精准检测、配置文件自动定位、核心参数读取展示到交互式核对确认的全流程闭环；同时打通了全链路 `model` 模型参数的解析与持久化同步。

---

## 🚀 核心更新

### 1. 全新软件启动初始化向导（Initialization Wizard）
- **竖直向下动态进度条（Vertical Stepper & Progress Rail）**：
  - 左侧步进器内置动态物理导轨与平滑渐变的色彩填充线（Blue $\rightarrow$ Indigo $\rightarrow$ Emerald），随环节推进自顶向下延伸（0% $\rightarrow$ 25% $\rightarrow$ 50% $\rightarrow$ 75% $\rightarrow$ 100%）。
  - 节点状态具备清晰的视觉反馈：等待（暗雅边框序号）、进行中（呼吸微光环 + 旋转加载指示）、成功（翡翠绿 + 白勾 `CheckCircle2`）、失败（鲜红警报 + `XCircle`）。
- **单次冷启动触发机制**：
  - 应用挂载时通过会话状态严格校验，仅在每次软件冷启动后自动唤起执行一次初始化流程，常规切换与界面重绘绝不重复弹出打扰用户。
  - 主界面顶部标题栏右侧贴心增设【初始化】快捷按钮，便于用户在任意时刻手动调出向导重新自检。

### 2. 四大环节严格顺序执行与故障阻断机制
各环节必须按前后顺序依次执行，当前环节通过后方可进入下一环节，任意环节失败均立即终止并给出明确反馈：
- **环节 1：网络环境精准检测**
  - **本机实际网络为依据**：后端调用 `reqwest` 向指定站点（`https://bob-api.com/`）发送真实 HTTP GET 请求，精确采集毫秒级延迟（`latency_ms`）与响应状态码（`200 OK`）。
  - **智能异常诊断**：针对连接超时、DNS 无法解析或非 200 响应等具体异常原因进行精准提示并终止流程，提供【重新检测】与【退出软件】操作。
- **环节 2：配置文件路径自动识别与定位**
  - 自动识别定位本机环境中的两套 Agent 配置文件路径：
    - **ChatGPT (Codex)**：`%USERPROFILE%\.codex\config.toml`
    - **Claude Code**：`%USERPROFILE%\.claude\settings.json`
  - 显示绝对路径与文件就绪状态标签，提供一键复制路径功能。
- **环节 3：核心配置信息读取与解析展示**
  - 自动读取并解析 TOML / JSON 配置文件内容，以现代化卡片排版呈现核心三大参数：
    1. **接口地址 (url)**：清晰展示并支持一键复制。
    2. **认证密钥 (apikey)**：默认进行脱敏掩码保护，提供一键明文/密文切换查看与快捷复制。
    3. **核心模型 (model)**：显示当前配置生效的模型标识（如 `gpt-5.6-sol` / `claude-sonnet-5`）。
  - 支持在弹窗内自由切换查看 ChatGPT 与 Claude Code 的配置卡片。
- **环节 4：配置信息检查与操作确认对话框**
  - 读取展示完毕后，弹出交互式确认对话框，提供两个明确选项供用户选择：
    - **选项 A（配置无误）**：核对无误后一键确认，标记步骤通过并点亮进度条至 100%。
    - **选项 B（需要修改配置）**：可在弹窗内直接展开快速修改表单，即时修改 url、apikey 或 model 并保存生效。

### 3. 流程控制闭环与安全退出通道
- **底部确认控制**：弹窗底部设计了醒目的【完成初始化并进入软件】渐变按钮，在环节 4 完成前保持锁定；确认后激活，点击即可关闭弹窗并正式进入主控制台。
- **安全退出通道**：若因无网络环境或路径异常导致初始化中断，提供基于 `@tauri-apps/plugin-process` 的【退出软件】按钮，防止程序陷入无响应或异常循环。

### 4. 跨面板核心模型参数（Model）全链路支持
- **Rust 后端数据契约扩展**：
  - `CodexConfig` 与 `ClaudeConfig` 新增 `model` 字段。
  - Codex 端支持识别根级 `model` 与 `profiles.thirdparty.model`，并在保存时双向同步写入。
  - Claude 端支持解析 JSON 根级 `model` 与 `env.ANTHROPIC_MODEL`。
- **主界面面板模型同步**：
  - [ChatGPTPanel.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChatGPTPanel.tsx) 与 [ClaudePanel.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/ClaudePanel.tsx) 实现配置加载时模型状态回显，并在保存时将 `model` 一并持久化，消除了模型配置的割裂。
