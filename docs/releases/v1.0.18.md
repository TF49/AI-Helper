# AI Helper v1.0.18

**发布日期**: 2026-09-25

AI Helper v1.0.18 聚焦于**配置真实性还原、初始化向导交互体验升级与免打扰持久化优化**。本版本彻底解决了以往版本中对模型（Model）字段过度“热心”注入默认值导致的配置混淆问题，同时赋予用户在初次使用时更自由便捷的向导控制体验。

---

## 🚀 核心更新

### 1. 消除虚假默认模型，还原客观真实配置（Model Truthfulness）
过去在读取 `settings.json`（Claude Code）与 `config.toml`（Codex）时，若文件中未配置 `model` 字段，后端会自动回退并注入硬编码的默认模型（如 `gpt-4o` 或 `claude-3-7-sonnet-20250219`），导致前端与向导误以为用户已配置模型：
- **后端解耦默认值强加**：
  - 在 [`codex.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/codex.rs) 与 [`claude.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/claude.rs) 中移除了自动回填缺省模型的逻辑；若本地配置中未指定模型，如实返回空字符串 `""`；
  - 同步更新了 6 项相关的 Rust 核心单元测试，确保在空配置、空白符、损坏 JSON/TOML 等边界情况下均能稳定返回真实空状态。
- **前端面板客观呈现**：
  - [`ChatGPTPanel.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChatGPTPanel.tsx) 与 [`ClaudePanel.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ClaudePanel.tsx) 的初始 `model` 状态统一初始化为空字符串，读取配置时严格遵循上报数据，不再默认伪造选中态。

### 2. 初始化向导自由度提升：随时关闭与一键跳过（Wizard Experience）
为了避免强制性的扫描流程影响老用户或快速上手体验，全面升级了初始化向导 [`InitializationModal.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/InitializationModal.tsx) 的交互控制：
- **右上角快速关闭按钮**：
  - 在顶部进度条右侧增加了独立的关闭（`X`）图标按钮，用户可随时打断向导进入主界面；
- **一键跳过向导直接进入**：
  - 底部操作栏左侧新增「跳过向导直接进入」轻量按钮，点击后立即完成初始化登记并无缝进入应用；
- **模型状态真实回显与防错**：
  - 扫描向导日志与核心卡片中，若模型未指定，客观展示为 `未配置 (空)` 状态，不再虚假显示默认预设；
  - 当模型为空时自动隐藏复制按钮，避免用户无意中将空白内容复制到剪贴板；
  - 优化子阶段文本描述，由原先的“映射核心推荐模型预设”精准修正为“读取核心模型配置与调用链参数”。

### 3. 持久化存储防重复弹窗打扰（Persistent Launch State）
- **从 Session 存储升级为 LocalStorage 持久化**：
  - 在 [`App.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/App.tsx) 中，将初始化向导的标记判断由单一会话级别的 `sessionStorage` 升级为浏览器本地持久化的 `localStorage`（键名 `ai_helper_init_completed`）；
  - 无论是完整走完向导、手动关闭窗口还是点击跳过向导，系统均会持久化已完成状态，确保后续重启软件时不再重复弹窗打扰。
