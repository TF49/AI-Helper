## 🌟 核心升级亮点 (Core Highlights) 💡✨💎🔑🔗

### 1. 🔑 密钥智能归一：带不带 `sk-`、明文还是脱敏，统统认成同一把 🧩✨

过去匹配逻辑散落在输入框、绑定 Hook、跨工具复用三条路上：有的要求字符串全等，有的按「前 7 + 后 4」抠脱敏，**一边带 `sk-`、一边不带就会对不上**，绑定分组瞬间「失踪」。😫👻  

**v1.0.68 在 [`useBoundTokenGroup.ts`](file:///e:/Developer%20Tool/AI%20Helper/src/lib/useBoundTokenGroup.ts) 抽出统一工具函数！** 🎉🔐

| 步骤 | 函数 | 做什么 |
|---|---|---|
| ✂️ **归一** | `normalizeApiKey` | `trim()`，若以 `sk-` 开头则剥掉前缀 |
| ✅ **比对** | `isKeyMatch` | 归一后全等 → 命中；否则长度 ≥ 10 时用 **前 6 + 后 4** 脱敏比对 |
| ♻️ **复用** | `matchTokenByKey` / `matchViaOtherToolBindings` / `matchTokenByFetchingKeys` | 全部改走 `isKeyMatch`，不再各写一套 |

[`ApiKeyInput.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ApiKeyInput.tsx) 同步删除重复的「精确匹配 + 脱敏再扫一遍」分支，**输入框、缓存绑定、跨工具借绑、按需拉明文，四条路口径一致！** 🛤️💚

```
+-----------------------------------------------------------------------------------+
|            🔑 v1.0.68 密钥比对流水线 (Key Match Pipeline)                           |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  🧾 输入框 Key  / 云端脱敏 Key  / getTokenKey 明文                                 |
|         │                                                                         |
|         ▼                                                                         |
|  ✂️ normalizeApiKey（去空格 · 剥 sk-）                                             |
|         │                                                                         |
|         ▼                                                                         |
|  ✅ 归一后全等？ ──✔️──► 同一把 Key 🎉                                             |
|         │ ❌                                                                       |
|         ▼                                                                         |
|  🕵️ 长度 ≥ 10 且 前6 + 后4 相同？ ──✔️──► 脱敏也认 🎉                              |
|         │ ❌                                                                       |
|         ▼                                                                         |
|  🚫 不是同一把，不解绑乱绑                                                          |
|                                                                                   |
+-----------------------------------------------------------------------------------+
```

---

### 2. 🏷️ 空分组强制回落 `default`：空白字符串再也冒充「没分组」 🛟💎✨

云端 Token 的 `group` 经常是空串、空格，甚至 `undefined`。过去写入绑定缓存时用 `group ?? undefined`，监控拿到空值就当成「未绑定」，**明明已选 Key，通道区却还在推「未配置 Key · 推荐最优通道」。** 😫📡  

**v1.0.68 一律 `token.group?.trim() || "default"`：** 🎯

- 🗃️ `toBoundInfo` / `ApiKeyInput` 选钥 / 工作台弹窗写入 `localStorage` 都带上归一后的分组；  
- 📡 [`ChannelGroupMonitor.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChannelGroupMonitor.tsx) 解析当前分组时：`currentGroupName` 与绑定分组都先 `trim`，**已有 Token id 但分组空 → 回落 `default`**；  
- 🔄 Hook 里 `setGroup` 改为读 `info.group`（已经回落过），避免「缓存是 default、界面还是 null」。

空分组不再是「失踪人口」，默认通道终于能对上监控大盘！✨💚

---

### 3. 📡 选 Key 即绑分组，并广播全工具同步（依然不带明文 Key） 🔀🛡️✨

过去工作台 Token 弹窗只把 `{id, name}` 塞进 `bound_token_${toolId}`，**分组当场丢掉**；其它工具也不会立刻跟上。  

**v1.0.68 在 [`App.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/App.tsx) 选钥回调补齐：** 🎉

1. 🏷️ `targetGroup = token.group?.trim() || "default"`；  
2. 🗃️ `localStorage` 写入 `{ id, name, group }`；  
3. 📡 `dispatchEvent("ai_helper_sync_all_tokens")`，`detail` 仍只有元数据（**不含明文 Key**，延续 v1.0.67 安全口径）；  
4. 🔔 [`ApiKeyInput.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ApiKeyInput.tsx) 选钥后立刻 `onBoundTokenChange?.(info)`，通道监控不用等下一轮拉取才刷新。

选一把 Key，当前工具分组立刻亮、其它 Agent 也能跟上——**钥、组、工具三条线一次对齐！** 🧩🚀

---

### 4. 💚 监控文案会说话：分清「没配 Key」和「没绑分组」 👀✨

同一套「推荐最优通道」徽章，以前不管有没有 Key 都写「未配置 Key」，让已经贴了密钥的用户一脸问号。😵  

**v1.0.68 按 `isKeyConfigured` 分流：**

| 场景 | 徽章文案 |
|---|---|
| 🚫 **真的没配 Key** | 「未配置 Key · 推荐最优通道」 / 「工具推荐默认 (未绑定专属 Key)」 |
| 🔑 **Key 已在，分组还没对上** | 「未关联分组 · 推荐最优通道」 / 「未关联专属分组 (推荐优质通道)」 |

推荐算法还在，**话术不再冤枉已经配好密钥的你！** 💬💚

## 📋 详细更新日志 (Changelog) 📑✨🎉🔑🔗📡

### 🔑 密钥归一与绑定匹配 (Key Match)
- **新增** `normalizeApiKey`：去空格并剥离 `sk-` 前缀，明文 / 脱敏 / 带不带前缀走同一坐标系。✂️🔑
- **新增** `isKeyMatch`：归一后全等比对，长度 ≥ 10 时用前 6 + 后 4 兼容脱敏展示。🕵️✅
- **重构** `matchTokenByKey` / `matchViaOtherToolBindings` / `matchTokenByFetchingKeys` 全部改用 `isKeyMatch`，删掉散落的 `startsWith` / `endsWith` 分叉。♻️🧹
- **精简** [`ApiKeyInput.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ApiKeyInput.tsx) 精确匹配 + 脱敏二次扫描，改为一次 `tokens.find(isKeyMatch)`。🧩✨

### 🏷️ 空分组回落与缓存写入 (Default Group)
- **加固** `toBoundInfo`：`group: token.group?.trim() || "default"`，导出供多处复用。🏷️🛟
- **加固** 输入框绑定刷新、选钥写入、工作台弹窗缓存，一律带上归一分组名。🗃️✨
- **修复** Hook 内 `setGroup` 读取已回落的 `info.group`，避免缓存与界面分组不一致。🔄💚
- **修复** [`ChannelGroupMonitor.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChannelGroupMonitor.tsx) `resolvedCurrentGroup`：空字符串不再生效，已绑 Token 无分组时回落 `default`。📡✅

### 📡 选 Key 同步与监控文案 (Sync & Copy)
- **增强** [`App.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/App.tsx) 工作台选钥：写入 `{id, name, group}` 并派发 `ai_helper_sync_all_tokens`（detail 不含明文 Key）。🛡️🔀
- **增强** `ApiKeyInput` 选钥后调用 `onBoundTokenChange`，通道监控即时刷新。🔔✨
- **优化** 推荐通道徽章：已配 Key 显示「未关联分组 · 推荐最优通道」；未配 Key 仍显示「未配置 Key · 推荐最优通道」。💚👀

### 📦 工程构建与官网同步 (Engineering & Releases)
- **升级** 应用版本号全面提升至 **`v1.0.68`**（`package.json`、`Cargo.toml`、`Cargo.lock`、`tauri.conf.json`）。🔖🚀
