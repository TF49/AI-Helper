# AI Helper v1.0.16

**发布日期**: 2026-09-25

AI Helper v1.0.16 是一次重大的**开发体验与连接可靠性里程碑更新**。本版本深度参考了业界优秀开源项目 [Sub2API](https://github.com/Wei-Shaw/sub2api.git) 的模型连接测试架构，为 ChatGPT (Codex) 与 Claude Code 带来了全新的**类终端（Terminal）实时交互探测与智能诊断验证流（Interactive Terminal Test & Live Diagnostics）**。

过去用户点击「保存并应用」时，系统仅在后台静默发起探测请求，缺乏透明的过程可视性；一旦发生鉴权失败、模型权限受限或节点故障，难以快速定位症结。在 v1.0.16 中，保存流程全面升级为**所见即所得的极客级终端弹窗**——实时呈现网络握手、延迟测速、模型回复与配置持久化全链路，并在测试通过后自动完成配置入库与系统环境变量注入。

---

## 🚀 核心更新

### 1. 极客风类终端实时测试弹窗（Interactive Terminal Test Modal）
彻底重构了配置保存与联机验证的交互链路，赋予开发者专业、通透的调试体验：
- **macOS 风格拟物终端视窗**：
  - 采用红、黄、绿三色经典窗口控制微晶圆点与深色代码画布（`#0d1117`），营造沉浸式的开发者终端质感；
  - 顶部状态栏动态集成毫秒级往返耗时（如 `245ms`）与服务器响应码（如 `HTTP 200`）专属状态芯片；
  - 配备动态闪烁光标（`_`）与全自动平滑滚屏（Auto-Scroll），让输出日志始终聚焦在当前执行阶段。
- **分级彩色 ANSI 风格日志输出**：
  - `[INFO]` 打印初始化环境、目标平台与协议类型（OpenAI Responses / Anthropic Messages）；
  - `[DIM]` 打印服务端点 URL 以及经脱敏处理的安全凭证（如 `sk-***abcd`），防止密钥外泄；
  - `[HTTP 200]` 实时输出上游服务器握手状态与高精度网络延迟；
  - `[RESPONSE]` 实时流式呈现上游模型返回的 Token 回复预览（如 `"Hello! How can I assist you today?"`）；
  - `[SAVE]` 打印本地配置文件写入与系统环境变量更新进度；
  - `[SUCCESS]` 打印最终成功状态，明确提示重启 VS Code / Codex / Claude 终端生效。
- **一键复制终端完整日志**：
  - 终端右上角常驻「复制日志」便捷按钮，点击后一键将带有时间戳的完整排错与握手日志写入剪贴板，方便跨设备协同或技术支持。

### 2. 基于 Tauri v2 Channel 的双向流式探测通道（Streaming Test Pipeline）
在底层通信架构上，摒弃了传统的单向死等机制，构建了高响应的流式通信管道：
- **Tauri IPC Channel 原生驱动**：
  - 在 [`api_test.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/api_test.rs) 中实现 `test_codex_stream` 与 `test_claude_stream`，利用 Tauri v2 的 `tauri::ipc::Channel<TestStreamEvent>` 直接将 Rust 后台探测事件流式推送至前端；
  - 前端 [`TerminalTestModal.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/TerminalTestModal.tsx) 与 [`api.ts`](file:///e:/Developer%20Tool/AI%20Helper/src/lib/api.ts) 无缝挂载事件监听，支持日志打印、内容追加与完成态回调。
- **双协议端到端精准探测**：
  - **Codex (ChatGPT)**：向上游发送轻量握手请求 `POST /v1/responses`（Payload: `"Hi"`），精准适配 Codex 专用的 OpenAI Responses 协议，并智能解析响应输出；
  - **Claude Code**：向上游发送 `POST /v1/messages`（`max_tokens: 16`，携带 `anthropic-version: 2023-06-01` 与 `x-api-key`），准确验证 Anthropic 专用网关可用性。

### 3. 智能状态码诊断与排错指引（Smart Failure Diagnostics）
当网络或鉴权出现异常时，终端不再仅给出抽象的“测试失败”，而是输出精准的上下文诊断指引：
- **HTTP 401 Unauthorized**：提示身份凭证无效，引导检查 API Key 拼写、空格或是否已被供应商吊销；
- **HTTP 403 Forbidden**：提示访问被拒绝，可能当前账号缺少指定模型权限，或所选专线节点存在 IP 地区限制；
- **HTTP 404 Not Found**：提示端点未找到，引导确认 Base URL 是否正确以及是否支持对应协议；
- **HTTP 429 Too Many Requests**：提示上游触发限流策略或账号额度已耗尽，建议稍后重试或检查账户余额；
- **HTTP 5xx Server Error**：提示上游节点或模型集群临时故障，建议切换备用反代节点；
- **网络超时与不可达**：请求超时（超过 20 秒）或 TCP 握手失败时，提示检查本地网络连接、代理网关及防火墙设置；
- **安全失败保护**：测试未通过时，系统自动拦截写入操作，保持本地现有可用配置完整不受损坏。

### 4. 自动化保存闭环与倒计时体验（Auto-Save & Smooth Countdown）
- **验证通过后自动持久化**：
  - 只有在模型真实握手成功后，才自动调用写盘逻辑，更新 `~/.codex/config.toml` 与环境变量 `CUSTOM_OPENAI_API_KEY`（Codex），或 `~/.claude/settings.json` 与环境变量 `ANTHROPIC_BASE_URL`（Claude Code）；
- **4秒无感倒计时自动关闭**：
  - 测试成功后，底部操作按钮自动切换为 `完成 (4s)` 倒计时并平滑递减，无需用户手动关闭弹窗；同时支持随时手动提前点击关闭；
- **失败现场保留与一键重试**：
  - 若测试失败，弹窗保留完整日志并展示「重新测试」按钮，方便用户现场排查调整后一键再次验证。
