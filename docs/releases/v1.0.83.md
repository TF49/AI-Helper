## 🎮 像素风明暗主题切换 🌞🌙🟪

标题栏的主题控件升级为像素风开关 🎨。开关以太阳与月亮呈现浅色、深色状态，并配有动态像素效果与更鲜明的状态变化 ✨🌌。

- 🖱️ **点击切换**：点按标题栏开关，在浅色与深色主题之间快速切换
- 👆 **拖动操作**：支持拖动开关滑块，松手后切换到对应主题
- 🌗 **状态一目了然**：太阳代表浅色主题，月亮代表深色主题
- 🔕 **安静不打扰**：标题栏主题开关关闭声音反馈，专注工作不被打断 🤫🎧
- 🧭 **系统跟随不冲突**：开启“跟随系统外观”时，应用自动采用系统主题；需要手动指定时，关闭该选项后即可通过标题栏开关切换 ⚙️🔄

> 💡 主题控制现在各司其职：标题栏负责快速切换浅色 / 深色，设置页负责决定是否跟随系统 🪄✅

## ⚙️ 设置体验整理：跟随系统，一键启用 🖥️🔄

“主题模式”区域改为简洁的 **跟随系统外观** 开关 🧭。启用后，AI Helper 会根据操作系统的外观设置自动选择浅色或深色模式 ☀️🌙；关闭后则保留当前解析出的主题，并可从标题栏手动调整 🎛️。

- ✅ **开启开关**：跟随操作系统外观变化
- ⬜ **关闭开关**：停止跟随，沿用当前浅色 / 深色外观
- 🧹 **减少重复选项**：快捷工具面板不再显示重复的主题选择区，主题设置更集中、更容易找到 🔍✨

## 🪟 工作台按钮：立体按压与流体玻璃 🫧💎

工作台 Agent 卡片上的 **一键配置** 与 **一键重启** 按钮采用全新的立体触感设计 🪄。悬停时表面轻轻下沉，按下时呈现更明确的反馈，透明玻璃高光则与卡片背景自然融合 👆✨。

- 🎛️ **更细腻的按压反馈**：用表面缩放、阴影和边缘高光表现悬停与点击状态
- 🫧 **玻璃质感更轻盈**：使用透明表面与柔和反光，按钮与 Agent 卡片更协调
- 🔄 **重启状态更直观**：正在重启时显示旋转中的进度图标 ⏳🔃
- 📐 **紧凑尺寸适配卡片**：按钮按工作台布局优化，保持操作清晰且不挤占卡片空间 🧩
- ♿ **尊重减少动态效果设置**：系统启用减少动态效果时，按钮动画会相应减弱或关闭 🛡️

### 🔍 玻璃效果兼容性说明

基础立体按钮和 CSS 玻璃高光在各桌面平台都可使用 🌐。文字透镜折射效果依赖 Chromium 渲染能力，在 Windows WebView2 中启用；在 macOS 等非 Chromium 环境中仍保留按钮本身的立体按压与玻璃高光效果 🪟🍎✨。

## ❓ 常见问题 FAQ 🧭💬

### 开启“跟随系统外观”后，还能从标题栏切换主题吗？ 🤔

标题栏开关用于手动切换浅色 / 深色主题；开启系统跟随时，应用会优先匹配操作系统的外观设置。想固定使用某一主题时，可先在设置页关闭“跟随系统外观”，再使用标题栏开关选择主题 🔄🌗。

### macOS 上看不到文字的玻璃折射效果，是异常吗？ 🍎

不是异常 ✅。文字透镜折射目前仅在 Chromium 渲染环境（例如 Windows WebView2）启用；非 Chromium 平台仍会显示立体按压反馈、透明表面与玻璃高光 🫧🪟。

### 这次更新会改变 Agent 配置或重启逻辑吗？ 🔧

本次仅调整工作台按钮的交互与视觉表现，配置和重启操作本身保持原有行为不变 ✅🔒。
