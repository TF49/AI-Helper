## 🌟 核心升级亮点 (Core Highlights) 💡✨💎🛡️📡

### 1. 🛡️ Accio Bridge 三道闸：Anti-CSRF · Anti-DNS-Rebinding · 受信 CORS 🏰✨

过去本地 Bridge 使用宽松 CORS，公网页一旦诱导浏览器打 `127.0.0.1:8787`，就可能盗刷账号额度。😫💸  
**v1.0.67 在 [`bridge.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/accio/bridge.rs) 落地中间件 `bridge_anti_csrf_middleware`！** 🎉🔐

| 闸门 | 检查什么 | 拦截效果 |
|---|---|---|
| 🏰 **Host 白名单** | `127.0.0.1` / `localhost` / `tauri.localhost` / `::1`（含端口与 IPv6 括号） | 公网 Host / DNS Rebinding → **403** |
| 🪪 **Origin 白名单** | `tauri://` · `vscode-webview://` · `file://` · `app://` · 本机 `http(s)` | 恶意站点 Origin → **403** |
| 🚫 **Sec-Fetch-Site** | `cross-site` 且 Origin 不受信 | 浏览器跨站探测 → **403** |
| 🌐 **CORS 收口** | 从 `CorsLayer::permissive()` 改为受信 Origin 谓词 | 预检也过不了陌生站点 |

空 Origin 仍允许本机 CLI / Agent 直连（无浏览器 Origin 头），真正做到「本地工具能用、公网页不能刷」！🛟💚

```
+-----------------------------------------------------------------------------------+
|            🛡️ v1.0.67 Bridge 请求安检流水线 (Security Gate)                         |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  🌐 入站请求                                                                      |
|         │                                                                         |
|         ▼                                                                         |
|  🏰 Host 是否受信本机？ ──❌──► 403 DNS Rebinding 拦截                             |
|         │ ✅                                                                       |
|         ▼                                                                         |
|  🪪 Origin 是否受信？ ──❌──► 403 CSRF 拦截                                        |
|         │ ✅                                                                       |
|         ▼                                                                         |
|  🚫 cross-site 且 Origin 不受信？ ──❌──► 403 跨站拦截                             |
|         │ ✅                                                                       |
|         ▼                                                                         |
|  ⏱️ 收费路径超限？ ──❌──► 429 流控拦截                                            |
|         │ ✅                                                                       |
|         ▼                                                                         |
|  🚀 进入健康检查 / LLM / MCP / 官方代理业务                                        |
|                                                                                   |
+-----------------------------------------------------------------------------------+
```

单测同步覆盖受信 / 恶意 Origin 与 Host（含端口、IPv6）！🧪✅

### 2. ⏱️ 滑动窗口限流：LLM 120 次/分 · 生图 6 次/分，死循环掏空额度直接刹车 🛑💎✨

恶意脚本或 Agent 卡死循环，一分钟就能把余额打穿。  
**v1.0.67 新增 `SlidingWindowRateLimiter`：** 🎯

| 端点类型 | 窗口 | 上限 | 超限 |
|---|---|---|---|
| 💬 **LLM / Embedding / rlab / MCP 代理** | 60 秒 | **120** 次（约 2 次/秒） | **429** + 中文可读原因 |
| 🖼️ **生图** | 60 秒 | **6** 次（成本极高） | **429** 拦截 |

收费路径识别 `is_monetized_bridge_path`：`/api/adk/llm` · `/api/adk/embedding` · `/api/tool/rlab/call` · `/api/mcp/proxy`。正常链式推理够用，刷额度脚本当场熄火！🧯✨

---

### 3. 🚫 防官方泄漏真正落地：开了开关就绝不回退、不透传阿里官方网关 🛰️✂️✨

过去 `prevent_official_leak` 开着，LLM 失败或 rlab 调用仍可能「好心」回退官方网关，请求与提示词有泄漏面。😫  
**v1.0.67 把开关做成硬拦截：**

- 🔁 LLM 失败且 `fallback_official=true` **同时** `prevent_official_leak=true` → **禁止回退**；  
- 🧰 `/api/tool/rlab/call` 开防泄漏 → 本地返回合规空成功，**不再转发官方**；  
- 📤 官方透明代理路径同样拦截，日志打出明确「防官方泄露已开启」。

「防泄漏」三个字，终于和实际行为对齐！🛡️💚

### 4. 🔏 热更新 SHA-256 验签：镜像再快，哈希不对也绝不装 📦🔐✨

多源下载方便国内用户，但也带来「反代被投毒」风险。  
**[`updater.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/updater.rs) 在安装前增加权威哈希对照：** 🎯

1. 多源拉取 `SHA256SUMS.txt`：官方直链 → GitHub Release → ghfast → gh-proxy → ghproxy.net；  
2. 解析目标包名（Windows Setup / macOS DMG）；  
3. 对临时安装包计算 SHA-256；  
4. **不一致立即删除文件并拒绝启动安装**，日志打出「安全警报」。

新增依赖 `sha2`；`parse_expected_hash` 有单元测试护航。找不到清单时降级告警但不误杀，有清单则绝不放过篡改包！🧪✅

```
+-----------------------------------------------------------------------------------+
|            🔏 热更新验签链路 (Update Integrity)                                     |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  ⬇️ 多镜像容灾下载安装包                                                           |
|         │                                                                         |
|         ▼                                                                         |
|  📄 拉取 SHA256SUMS.txt                                                           |
|         │                                                                         |
|         ├── 找到对应文件名哈希                                                      |
|         │         │                                                               |
|         │         ▼                                                               |
|         │   🧮 compute_file_sha256                                                |
|         │         │                                                               |
|         │         ├── ✅ 一致 → Finished → 调起安装 🎉                             |
|         │         └── ❌ 不一致 → 删临时文件 → 拒绝安装 🚨                         |
|         │                                                                         |
|         └── 未找到清单 → 告警并继续（兼容旧发版） ⚠️                                |
|                                                                                   |
+-----------------------------------------------------------------------------------+
```

### 5. 📡 通道监控智能化：工具专属指南 · 最健康分组推荐 · 倍率徽章一眼看懂 💚📊✨

[`ChannelGroupMonitor.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChannelGroupMonitor.tsx) 本版大幅增强，四大工具面板（Codex / Claude / WorkBuddy / Accio）都会带上「当前是否已配 Key + 当前分组」！

#### 🧰 1. 工具专属分组与密钥规则
每种 Agent 都有独立指南卡片：推荐关键词、协议特性、写到哪份配置、绑错分组会怎样（超时 / 404 / 模型不可用）。

| 工具 | 专属标签 | 推荐关键词方向 |
|---|---|---|
| 🔵 **Codex** | 流式专用 | codex · svip-codex · openai · gpt |
| 🟣 **Claude Code** | Anthropic 深度推理 | claude · kiro · anthropic |
| 🟢 **WorkBuddy** | 多模型聚合 | workbuddy · all · svip · default |
| 🟠 **Accio Work** | 企业级 Bridge | accio · bridge · enterprise · svip |

#### 💚 2. 多因子「最健康最稳定」算法 `findHealthiestAndStableGroup`
1. 优先在当前工具推荐关键词分组里挑；  
2. 成功率（≥ 0.5% 差异才算主导）→ 有真实流量优先 → 时延更低 → 承载请求量更大；  
3. 专属通道成功率 **&lt; 85%** 则全局兜底选最优。  
**未配置 Key 时，监控区直接展示推荐最优通道**，不再空白干等！✨

#### 💰 3. 分组倍率徽章
优惠 / 1.0x 标准 / 较高 / 高倍率（带警示三角），对比预览时也会标「临时对比预览」。

- **新增** `is_trusted_bridge_origin` / `is_trusted_bridge_host`：只放行本机与桌面内嵌 Origin / Host。🏰
