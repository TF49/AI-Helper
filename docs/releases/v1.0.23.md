## 🚀 详细更新亮点

### 1. ⚡ 全链路国内极速更新生态与六级金字塔灾备回退 (Ultra-Fast Mirror & Multi-Tier Fallback Updater)

- 🌏 **直击国内网络环境长期痛点**：
  - 在以往版本中，自动更新依赖 GitHub Releases 原生直连；在中国大陆无代理或无 VPN 的网络环境下，直连 GitHub 或 AWS S3 (`objects.githubusercontent.com`) 下载安装包往往遭遇 DNS 污染、握手超时、下载卡死或速度仅几 KB/s 的恶劣体验 😫💔；
- 🚄 **发版清单镜像全量注入 (`package-release.ps1`)**：
  - 构建发版打包脚本全面升级！自动化生成的最新版本清单 `latest.json` 中，Windows 平台安装包下载 URL 默认注入 `https://ghfast.top/https://github.com/TF49/AI-Helper/releases/download/...` 国内高速反代镜像 🚀📦；
  - 客户端通过 Tauri 内置原生 Updater 拉取安装包时，直接无缝走国内高速镜像通道，实现极速满速下载，告别漫长等待与更新假死 ⚡💨；
- 🛡️ **Tauri Updater 多源端点守护矩阵 (`tauri.conf.json`)**：
  - 在客户端 Tauri 配置文件中，`plugins.updater.endpoints` 数组接入三级稳健安全防线 🛡️：
    1. 🥇 **`ghfast.top` 国内高速镜像清单**：国内用户首选，毫秒级响应；
    2. 🥈 **`gh-proxy.com` 国内高可用备用镜像清单**：高可用次级灾备节点；
    3. 🥉 **`github.com` 官方原生备用通道**：国际网络环境与代理环境兜底；
  - 无论单个镜像节点出现何种网络抖动，应用均能无缝按序自动探测，确保更新信息永远通畅 🔄🌐；
- 🏛️ **Rust 后端六级金字塔式灾备检测链 (`src-tauri/src/updater.rs`)**：
  - 将原先单一的更新检查逻辑重构为严密、稳健的 **6 级渐进式容灾回退架构** 🪜⚡：
    - ⚡ **Level 1**: `updater.json (ghfast)` —— 国内高速首选通道，极速拉取最新清单；
    - 🔄 **Level 2**: `updater.json (gh-proxy)` —— 国内备用加速通道，双重保险；
    - 🌐 **Level 3**: `updater.json (GitHub)` —— 官方源直连，海外用户或 VPN 环境自动适配；
    - 📦 **Level 4**: `jsDelivr CDN (package.json)` —— 全球公共 CDN 静态加速探测；
    - 🚀 **Level 5**: `GitHub Raw (ghfast)` —— 国内反代 package.json 极速读取兜底；
    - 🎯 **Level 6**: `GitHub Releases API` —— 官方 RESTful API 终极底牌；
  - 每一级更新源探测失败均会在后端控制台记录清晰详尽的警告日志，并自动优雅降级至下一级，并在 `source` 字段中透传实际命中的通道标识（如 `updater.json (ghfast)`），让网络诊断与故障排查一清二楚 📊🩺！

### 2. 🛡️ 强制更新模态框人性化蜕变与自由放行机制 (Force Update UX Evolution)

针对更新过程中可能出现的各种网络偶发异常与使用场景，对 `ForceUpdateModal` 进行了多项人性化重构与交互解耦 🌈✨：

- 🚀 **新增「国内高速下载」直通车 (`getAcceleratedDownloadUrl`)**：
  - 前端新增智能版本解析与镜像直链组装算法，秒级拼接 `ghfast.top` 国内加速安装包直链 💎；
  - 在 **「自动安装包暂未就绪 (`manual`)」** 场景下：提供醒目的深蓝主操作按钮 **「国内高速下载」** 🚄，并保留浅灰色的「GitHub」次级按钮与「稍后」按钮，用户一键即可直达浏览器高速下载，告别死等；
  - 在 **「下载异常/网络中断 (`error`)」** 场景下：除提供原生的「重试下载」外，新增独特的祖母绿高亮 **「国内高速下载」** 按钮 🟢，即使客户端内置更新受网络限制中断，开发者也能一键调起浏览器满速手工下载，立即脱困！
- 🔓 **告别霸道阻断：右上角常驻关闭与随时放行**：
  - 彻底移除了右上角关闭按钮原有的严格状态限制（旧版仅在就绪或报错时显示），升级为 **全周期常驻关闭按钮 (`X`)**，用户随时可以关闭弹窗稍后处理 🚪✨；
  - 针对大文件下载过程，特别在下载进度条下方增设了 **「稍后更新（后台放行）」** 按钮 🕒💼：
    - 即便当前正在下载安装包，如果开发者手头有紧急的 Agent 配置调试任务，可随时点击一键放行进入主界面；
    - 尊重开发者的工作节奏，彻底杜绝强弹窗霸屏打断心流的糟糕体验 🧘‍♂️！
- 🎨 **按纽层级与状态语义精细打磨**：
  - 为所有交互按键补齐 `cursor-pointer` 与细致的悬浮高亮反馈，操作体验如丝般顺滑 🖱️✨。

### 3. 🧹 CLI 安装命令精简提炼与纯粹化 (Clean & Focused CLI Setup)

回归极简与纯粹，让刚进入 AI 辅助编程的新手与老手都能以最快路径就绪 🌿⚡：

- 💎 **剔除冗余依赖，回归产品纯粹**：
  - 全面清理了界面中对第三方项目（如 `cc-switch`）的多余依赖标识与外链，让产品视觉更加聚焦、专业与轻盈 🍃；
- ⚡ **收敛官方标准精炼安装命令**：
  - **Claude Code CLI**：安装选项收敛为 Anthropic 官方推荐的标准精简全局命令：  
    `npm i -g @anthropic-ai/claude-code` 🦄
  - **OpenAI Codex CLI**：安装选项收敛为 OpenAI 官方推荐的标准精简全局命令：  
    `npm i -g @openai/codex` 🤖
  - 移除了多余且容易造成初学者选择困难的冗余分支，保留最通用的 Node.js 18+ 全局生态标准方案；
- 🧭 **初始化向导全面对齐 (`InitializationModal.tsx`)**：
  - 当开机/初始化扫描未检测到环境时，回退引导卡片内的命令同步更新为最精炼的标准语法，支持一键点击复制并呈现反馈动画 📋🪄！

### 4. 🦀 Rust 核心层代码质量净化与 Clippy 零警告 (Rust Quality & Modernization)

代码健壮性与现代 Rust 语法范式的持续打磨 💎🛡️：

- 🧼 **消灭 Clippy `unnecessary_map_or` 代码坏味道**：
  - 在 `src-tauri/src/claude.rs` 与 `src-tauri/src/codex.rs` 中，对路径存在性校验逻辑进行现代化重构 🦀；
  - 全面使用 Rust 1.70+ 现代惯用方法 `.is_some_and(|p| !p.is_empty() && std::path::Path::new(p).exists())`，替代了冗长陈旧的 `.map_or(false, ...)` 结构；
  - 消除全部编译器静态分析警告，提升代码的语义表达力与执行安全性 ⚡；
- 📐 **全局代码格式化规整 (`cargo fmt`)**：
  - 后端 Rust 源码全量运行官方 `cargo fmt` 深度格式化，消除微小排版缩进瑕疵，保持工业级代码库的整洁统一 📏✨；
- 🔒 **全链路构建零瑕疵交付**：
  - 前端通过 TypeScript 严格类型检查，后端编译零 Warning，确保运行时极高稳定性 ✅！
