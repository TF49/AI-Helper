# BobAPI Tool v1.0.11

**发布日期**: 2026-09-24

BobAPI Tool v1.0.11 是一次聚焦于**无边框沉浸式窗口视觉重构**与**全局弹性布局流体体验优化**的重要版本。本次更新彻底启用了原生无边框与系统级阴影支持，定制了全局极简优雅的高颜值滚动条，系统性修复了 Flex 弹性盒在各层级的溢出与高度截断问题，并对模型输入选择组件进行了轻量化精简，带来更加纯粹、流畅、现代的桌面交互质感。

---

## 🚀 核心更新

### 1. 原生无边框沉浸式窗口设计（Frameless & Shadow）
- **全面启用无边框模式（`decorations: false`）**：
  - 移除了原有的系统原生与混合标题栏配置（`titleBarStyle: "Overlay"` / `"Visible"`），彻底转为现代化无边框视窗。
  - 完美契合前端自绘制的高颜值自定义标题栏、窗口拖拽区与最小化/关闭控制按钮，杜绝了 Windows 原生边框与自绘 UI 的视觉断层与冲突。
- **系统原生阴影支持（`shadow: true`）**：
  - 在全平台及 Windows 专属配置中开启原生立体阴影渲染，使无边框窗口在深色/浅色桌面背景下均具备自然的悬浮层级与精致轮廓。

### 2. 全局弹性布局防溢出与滚动机制重构
系统性地解决了 Flex 弹性盒在嵌套时因内容自适应而导致的父级被撑破、局部滚动失效以及小屏幕显示裁切问题：
- **`#root` 根容器高度约束**：增加 `min-height: 0` 与 `overflow: hidden`，构建可靠的视口边界基准。
- **`AuroraBackground` 极光背景层规范**：内外层统一注入 `h-full min-h-0`，确保动态发光光晕与前景交互内容严格适配视口，杜绝溢出抖动。
- **主面板独立滚动区保障**：[App.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/App.tsx) 内容区添加 `min-h-0` 约束，确保无论卡片内容多长均能在可视区内丝滑局部纵向滚动。
- **初始化向导小窗口适配**：[InitializationModal.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/components/InitializationModal.tsx) 移除了过往写死的 `min-h-[460px]` 限制，改为弹性 `min-h-0` 自适应，完美适配小尺寸屏幕与不同 DPI 缩放。

### 3. 全局极简优雅微光滚动条（Custom Scrollbar）
在 [index.css](file:///e:/Developer%20Tool/Bobapi%20Tool/src/index.css) 中为全应用注入了精致的定制化滚动条样式，彻底替换浏览器粗重突兀的原生滑块：
- **超细 6px 极简胶囊滑块**：采用完全透明的轨道背景与圆角胶囊滑块，在不破坏页面留白美感的前提下呈现滚动位置。
- **智能深浅色微光交互**：
  - **浅色模式**：雅致柔和的半透明 Slate 灰滑块（`rgba(148, 163, 184, 0.4)`），悬停平滑加深过渡。
  - **暗黑主题**：微透亮白滑块（`rgba(255, 255, 255, 0.2)`），悬停触发动态提亮（`rgba(255, 255, 255, 0.35)`），与深邃背景高度协同。
- **双引擎兼容器**：同步支持 WebKit/Blink 内核与 Firefox 现代 `scrollbar-width: thin` 标准。

### 4. 模型输入组件轻量化精简（Model Input Streamlined）
- **移除冗余的硬编码预设芯片**：
  - 从 [ModelInput.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/components/ModelInput.tsx) 中移除了旧版本固化在界面的推荐标签流（`presetSuggestions` 与 `Sparkles` 图标），使组件聚焦于输入、动态 Popover 检索与远程拉取。
  - 避免硬编码的旧版推荐模型与后端/中转站动态获取的最新模型列表产生认知冲突，大幅减少界面视觉噪音。
- **操作面板间距优化**：
  - [ChatGPTPanel.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/components/ChatGPTPanel.tsx) 与 [ClaudePanel.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/components/ClaudePanel.tsx) 移除过期预设列表依赖，面板底部间距调整为 `pb-4`，提供更舒适的视觉呼吸感。

### 5. 版本全链路同步升级
- 同步推进应用版本由 `v1.0.10` 升级至 `v1.0.11`，全量更新了前端与 Rust 后端的核心元数据文件：
  - `package.json`
  - `src-tauri/Cargo.toml`
  - `src-tauri/Cargo.lock`
  - `src-tauri/tauri.conf.json`
  - `src-tauri/tauri.windows.conf.json`
