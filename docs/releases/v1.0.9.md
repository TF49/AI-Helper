# AI Helper v1.0.9

**发布日期**: 2026-09-24

AI Helper v1.0.9 带来了全新的自动更新体系与界面交互体验重构，彻底解决了窗口滚动与分辨率适配问题，并全面复用了成熟开源项目 Antigravity-Manager 的升级更新逻辑。

---

## 🚀 核心更新

### 1. 全新自动更新机制（对标 Antigravity-Manager）
- **多源 Fallback 检测体系**：新增四级降级检测机制（`latest.json` 权威源 → `GitHub Releases API` → `GitHub Raw` → `jsDelivr CDN`），极大提升在网络受限环境下的检测成功率。
- **系统代理环境变量支持**：后端自动探测并复用系统的 `HTTPS_PROXY` / `HTTP_PROXY` / `ALL_PROXY` 代理配置，并无缝传递给前端更新器，彻底解决国内网络环境直连 GitHub 下载更新超时的问题。
- **启动无感静默检测**：软件打开后延迟 1.5 秒在后台静默检测，不阻塞界面渲染。无更新时完全不打扰用户；发现新版本时即刻唤起下载卡片，展示实时下载速度与百分比进度条。
- **平滑安装与一键重启**：更新包下载完成后自动校验并安装，支持点击【立即重启生效】或选择稍后重启。
- **手动检查更新交互优化**：点击底部状态栏【检查更新】可即时触发检测，已是最新版时将弹出 Toast 明确提示（如 `当前已是最新版本，无需更新`），不再有假死感。

### 2. 界面布局与滚动体验重构
- **修复小窗口无法上下滚动问题**：重构外层容器布局结构，移除 `body` 的视口高度锁死限制，内容超出容器时通过内部弹性滚动区流畅响应鼠标滚轮。
- **消除窗口放大底部的黑色色块**：优化全局背景配色与暗色主题继承机制，确保窗口在任意缩放、拖拽或全屏最大化时均能完美铺满，消除断层与黑边。

### 3. 版本号显示校准
- 移除底部状态栏固定的硬编码版本文本，全面改用 `@tauri-apps/api/app` 接口动态获取当前运行版本，精准显示当前软件真实版本号。
