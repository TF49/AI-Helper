### 1. 🗂️ 全新「应用与 CLI 安装路径管理」面板 (Process & Path Discovery)

以往用户需要手动猜测或在不同目录下寻找 Claude、Codex 或 ChatGPT 的安装路径，配置繁琐且容易出错。v1.0.20 隆重推出独立的路径管理中心：

- 🧭 **三大主流工具全覆盖**：
  - 🟣 **Claude Code CLI**：支持全局 npm 脚本 (`%APPDATA%\npm\claude.cmd`) 及 PATH 变量定位；
  - 🔵 **Codex CLI**：支持全局 npm 命令 (`codex.cmd`) 及原生可执行程序定位；
  - 🟢 **ChatGPT 桌面端**：深度支持 **Microsoft Store 应用包** (`WindowsApps\OpenAI.Codex_*`) 与 **Win32 独立安装版** (`%LOCALAPPDATA%\Programs\ChatGPT`)。
- 🔍 **一键全量深度探测 (Auto Detection)**：
  - 支持单项探测与「一键全量深度探测」；
  - 采用 **多级优先级回退算法**：`当前运行进程实时提取` ➔ `NPM 全局安装路径` ➔ `系统 PATH 环境变量` ➔ `标准程序目录` ➔ `Store 应用包降序版本排序`；
  - 自动过滤版本残留目录，始终匹配并选用最新版本。
- 📂 **原生文件浏览与安全校验**：
  - 集成 Windows 原生文件选择对话框，支持快速点选 `.exe` / `.cmd` / `.bat`；
  - 对输入参数实施严格白名单校验，杜绝任何外部参数注入隐患。
- 💾 **自动持久化与自愈**：
  - 路径配置自动持久化存储于 `~/.ai-helper/app_paths.json`；
  - 当客户端发生更新导致旧路径失效时，系统启动时将自动触发动态自愈探测并回写。
- 🎮 **独立测试启动**：
  - 每张卡片均提供「测试启动」按钮，支持在独立终端或前台一键唤起验证；
  - 配备实时「运行中」脉冲指示灯（Pulsing Badge）与加载状态锁。

### 2. 🔄 终端连通性测试后：一键平滑重启客户端引导 (Smart Restart Workflow)

在过去的流程中，当配置写入 `config.toml` 或 `settings.json` 后，需要用户手动在任务管理器或托盘中退出客户端再重新开启。现在，整个流程全自动化：

- 🤖 **连通性测试通过后智能感知**：
  - 测试通过并成功部署配置后，后台自动嗅探目标客户端与 CLI 的实时运行状态；
  - 弹出专属 **「客户端重启确认引导面板」**，清晰告知当前客户端是“运行中”还是“未运行”。
- 🚀 **多目标灵活重启 / 启动通道**：
  - 🟢 **ChatGPT 模式**：提供「重启/启动 ChatGPT 客户端」与「重启/启动 Codex CLI 终端」双独立按钮；
  - 🟣 **Claude 模式**：提供「重启/启动 Claude Code 终端」专属按钮；
  - ⚪ **灵活控制**：提供「稍后自行重启」与底部「完成」按钮，彻底移除打扰性的强制倒计时关闭，操作自由不打断。
- 🛡️ **底层安全进程树熔断 (Process Tree Clean-up)**：
  - Windows 环境下使用 `taskkill /F /T /PID` 确保完整清理子进程树（如 Node / Electron 孤儿进程），避免端口占用或配置锁死；
  - 内置有界轮询等待机制（最长 2.5 秒，每 150ms 轮询），确保旧进程完全释放文件句柄后再拉起新实例，彻底杜绝多实例竞争崩溃。

### 3. ⚡ 底层架构级性能优化与异步非阻塞调度 (High-Performance Engine)

为了保障桌面客户端极致流畅的交互体验，在 Rust 后端和 Tauri 通信层进行了深度重构：

- 🏎️ **进程扫描从 6 次降至 1 次 (Single Process Snapshot)**：
  - 原先全量探测时会为每个目标分别扫描两次系统进程树（共 6 次全局进程遍历）；
  - 重构后引入 `inspect_target_process_with_system`，**仅需单次刷新系统进程快照**即可并发完成三大应用的状态判断，显著降低 CPU 瞬时开销与等待延迟。
- 🧵 **Tauri 命令线程非阻塞化 (`tokio::task::spawn_blocking`)**：
  - `restart_target_app` 命令全面升级为异步命令；
  - 将进程杀灭、状态轮询休眠及启动逻辑调度至专用阻塞线程池中执行，主异步 Worker 线程零等待，保证流式测试与 UI 动画丝滑不卡顿。
- 🛡️ **ChatGPT 启动协议防御性判定**：
  - 修正了非 Store 版路径缺失时错误回退至 `shell:AppsFolder` 的逻辑缺陷，未找到有效程序时给出准确友好的配置指引。

---

### 4. 🧰 快速诊断工具箱：双协议一键切换 (Protocol Switcher)

针对拥有多套模型服务环境的开发者，升级了侧边栏的「快速诊断工具箱」：

- 🔀 **内置 [OpenAI / Claude] 协议切换药丸**：
  - 在 cURL 测试脚本区域新增药丸式切换器，点击即可在 OpenAI 格式 (`/v1/chat/completions`) 与 Anthropic 格式 (`/v1/messages`) 之间自由切换；
  - 无论是配置 API 还是在「路径管理」页面调试，脚本与环境参数都一清二楚。
- 🧭 **智能上下文记忆**：
  - 侧边栏引入 `lastAgentTab` 状态跟踪，记录用户最近使用的模型面板，工具箱打开时默认对齐当前业务场景。

### 5. 🎨 细节体验与界面交互优化 (UI & UX Polish)

- ⏳ **状态防抖与内存安全**：
  - `AppPathsPanel` 使用 `useRef` 统一接管延迟轮询定时器，在组件注销或重复点击时自动销毁清理，彻底杜绝控制台警告与内存泄漏。
- 🔒 **按键防误触与视觉反馈**：
  - 为所有卡片的「探测」、「测试启动」和顶部的「重新载入」按钮统一配置 `disabled:opacity-60 disabled:cursor-not-allowed` 样式与 Loading 旋转动效，防止并发误触。
- 🧹 **模态框全生命周期状态重置**：
  - `TerminalTestModal` 在关闭时深度清理历史流式日志、HTTP 状态码、延迟时间及重启卡片显示状态，确保每次唤起均呈现干净清爽的终端界面。
