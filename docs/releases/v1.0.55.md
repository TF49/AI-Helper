## 🌟 核心升级亮点 💡✨

### 1. 🗂️ 侧边栏折叠双模架构：紧凑图标轨 (Rail) 与完整展开随心切换，最大化沉浸工作台 🖥️🚀

为了给用户提供更加开阔、无干扰的配置与调试展台，本次更新对主界面侧边栏进行了革命性的双模态重构：

```
+-----------------------------------------------------------------------------------+
|  [Logo] AI Helper  [Ctrl+B 收起/展开]             [后台常驻]  [-]  [□]  [✕]      |
+----------------------+------------------------------------------------------------+
| 🗂️ 完整模式 (256px)   | 🖥️ 右侧主工作台沉浸展台                                      |
| 或 紧凑图标轨 (68px)  |                                                            |
| ⚡ 极速切换自适应      | 宽度自动弹性舒展，代码/配置预览更清晰，空间利用率飙升 100% 🚀 |
+----------------------+------------------------------------------------------------+
```

#### 📐 1. 双形态自由切换：完整展开 (256px) ⇄ 紧凑图标轨 (68px) ⚡
- 🌟 **完整展开模式 (Full Sidebar Mode, `w-64 p-3.5`)**：包含各平台专属 Logo、名称、配置文件全名（`config.toml`、`settings.json`、`models.json` 等）、右侧高亮指示箭头，直观清晰！
- 🚀 **紧凑图标轨模式 (Compact Rail Mode, `w-[68px] p-2`)**：侧边栏自动收缩为精致的小图标轨，保留各平台标志性品牌色、激活指示竖条、圆角卡片底色与微投影（`shadow-2xs`），配置展台瞬间获得额外 **近 200px** 的横向视野！
- 💎 **精致底部微卡片**：在紧凑模式下，底部用户头像、网络连通性指示呼吸灯、Tauri 引擎/更新检测按钮均无缝转为微型图标矩阵，悬停带有原生 Tooltip 提示，小巧而全能！

#### ⌨️ 2. 极客标配快捷键：`Ctrl+B` / `Cmd+B` 毫秒级折叠响应 ⚡
- 🎯 **一键隐现**：无论是 Windows 上的 `Ctrl+B` 还是 macOS 上的 `Cmd+B`，随时敲击即可瞬间收折/展开侧边栏；
- 🛡️ **智能输入焦点守卫 (Input Protection)**：
  ```tsx
  // 仅在非输入状态下响应快捷键，杜绝文本打字冲突
  const active = document.activeElement;
  const isInput =
    active &&
    (active.tagName === "INPUT" ||
      active.tagName === "TEXTAREA" ||
      (active as HTMLElement).isContentEditable);
  if (!isInput) {
    e.preventDefault();
    toggleSidebarCollapsed();
  }
  ```
  在编辑 API Key、输入端口或搜索框打字时，绝对不会误触发侧边栏折叠，贴心兼顾每一处输入体验！✨

#### 💾 3. 用户偏好状态本地持久化 (`localStorage`) 🧠
- 📌 记录 `ai_helper_sidebar_collapsed`，无论重启应用或刷新窗口，均自动保持你最舒适的工作布局！

### 3. 🧩 滑块人机验证手感再升华：0 延迟物理级跟手 + 坐标公式精准重塑 🖱️💨

在 [`src/components/auth/SlideCaptchaModal.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/auth/SlideCaptchaModal.tsx) 中，针对拖拽响应延迟与位移计算公式进行了底层重构：

#### 🏎️ 1. 拖拽瞬间 0 延迟极速跟手 (`isDragging` 动态 Transition 剥离) ⚡
- ⚠️ **旧版痛点**：滑块进度条与手柄默认带有 `transition-all` 过渡动画，在快速滑动时会产生轻微的“滞后拖拽感”与“橡皮筋粘连”；
- 🚀 **新版革新**：引入拖动状态动态条件样式：
  ```tsx
  {/* 拖动中物理级 0 延迟实时跟随；释放后享受 200ms 丝滑平滑过渡 */}
  className={`absolute ... ${
    isDragging ? "transition-transform" : "transition-all duration-200"
  }`}
  ```
  拖动时指针走到哪里，滑块与高亮条便 **毫无保留地 100% 毫秒级跟进**，松手验证失败复位时则优雅平滑回弹，操作手感犹如丝绸般顺畅自然！💎✨

#### 📐 2. 滑块位移坐标算式重构 (Precision Calc) 🎯
- 🔍 **旧版算式**：`left: calc(${sliderPercent}% * (1 - 40px / 100%))`，在特定高分屏缩放与 Webview2 内部偶发浮点数解析不均；
- 🎯 **新版算式**：
  ```tsx
  left: `calc(${sliderPercent}% - ${sliderPercent * 0.4}px)`
  ```
  简化为一元线性位移，消除嵌套百分比计算负担，保证拼图滑块从起点 `0%` 到终点 `100%` 全程严密贴合轨道，无任何亚像素越界或抖动！🌟
