# BobAPI Tool v1.0.13

**发布日期**: 2026-09-24

BobAPI Tool v1.0.13 是一次聚焦于**桌面全屏视窗交互体验**、**大屏响应式优雅布局重构**与**原生系统默认浏览器外部链接接管**的关键版本。针对大屏及高分屏桌面环境下小窗口空间受限、无边框视窗缺少最大化控制、外部网页无法顺畅唤起系统浏览器等问题，本次更新对桌面视窗控制进行了全流程升级，支持默认最大化全屏显示、标题栏双击缩放、全屏/还原按钮动态响应，并基于 Rust 后端构建了原生的外部浏览器调用通道（Native URL Opener），配合全局自适应居中与双列节点网格布局，使软件在任何分辨率下均呈现出开箱即用的大气视效与生产力桌面质感。

---

## 🚀 核心更新

### 1. 全屏最大化支持与窗口交互控制全面升级（Window Controls & Maximize）
- **软件启动默认全屏最大化显示**：
  - 在 [tauri.conf.json](file:///e:/Developer%20Tool/Bobapi%20Tool/src-tauri/tauri.conf.json) 与 [tauri.windows.conf.json](file:///e:/Developer%20Tool/Bobapi%20Tool/src-tauri/tauri.windows.conf.json) 中将窗口默认尺寸从原本局促的 $460 \times 500$ 升级为舒适的 $1000 \times 650$（最小尺寸 $900 \times 600$），并开启 `"maximized": true`。
  - 在 Rust 原生启动钩子 [lib.rs](file:///e:/Developer%20Tool/Bobapi%20Tool/src-tauri/src/lib.rs) 的 `setup` 阶段显式调用 `window.maximize()`，彻底解决 Windows 桌面冷启动时的窗口闪烁与尺寸不足问题。
- **自定义标题栏新增“最大化 / 向下还原”控制按钮**：
  - 在 [App.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/App.tsx) 自绘制高颜值沉浸式标题栏右侧，在最小化与关闭按钮之间新增窗口最大化切换按钮。
  - 动态状态感应：结合 `Maximize2` 与 `Minimize2` 图标，根据窗口实时状态自动切换图标与浮动 Tooltip 提示（“最大化” / “向下还原”）。
- **双击标题栏智能最大化/还原**：
  - 遵循桌面操作系统经典操作逻辑，用户在标题栏任意非按钮区域双击时，均可即刻触发 `toggleMaximize()` 进行全屏与窗口化切换。
- **窗口尺寸与状态实时监听**：
  - 接入 Tauri 窗口 `onResized` 事件监听器，无论用户通过系统快捷键（如 `Win + ↑`）、窗口拖拽靠边（Aero Snap）还是界面按钮缩放，前端标题栏图标与状态均保持毫秒级同步。

### 2. 宽屏响应式自适应与居中优雅布局重构（Responsive Centered Layout）
针对最大化后大屏幕视口过宽可能导致表单拉伸失真、元素过于离散的问题，对全应用视口布局进行了精细的栅格与约束升级：
- **核心容器 `max-w-4xl` 居中规范**：
  - 在 [App.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/App.tsx) 中对网络连通性状态指示条、Tab 胶囊切换栏、主配置内容操作区以及底部状态栏统一注入 `max-w-4xl mx-auto w-full` 约束。
  - 使界面在无论是 $1080\text{p}$、$2\text{K}$ 还是超宽带鱼屏上全屏运行时，核心卡片与表单均保持黄金视宽居中陈列，视觉舒适自然。
- **预设节点卡片升级自适应双列网格**：
  - 在 [NodeCardSelector.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/components/NodeCardSelector.tsx) 中，将原本纵向单列卡片（`grid-cols-1`）重构为自适应双列布局（`grid-cols-1 sm:grid-cols-2 gap-2.5`）。
  - 充分利用宽屏横向空间对称展示 4 个预设官方优质专线节点，卡片高度更紧凑，重要信息（节点名称、地址、状态、标签）一览无余。

### 3. 原生系统默认浏览器外部链接接管（Native System Browser Opener）
彻底解决桌面 Webview 容器内部点击普通 `<a target="_blank">` 无法跳转、行为异常或被安全策略拦截的顽疾：
- **Rust 后端高性能 Native Opener**：
  - 在 [Cargo.toml](file:///e:/Developer%20Tool/Bobapi%20Tool/src-tauri/Cargo.toml) 引入轻量级原生外部应用唤起库 `opener = "0.8.5"`。
  - 在 [lib.rs](file:///e:/Developer%20Tool/Bobapi%20Tool/src-tauri/src/lib.rs) 中实现高效非阻塞的 Tauri Command `open_url`，通过 `tokio::task::spawn_blocking` 在后台线程调用系统关联的默认浏览器，杜绝任何 UI 线程卡顿。
  - **严格的协议白名单安全过滤**：仅放行 `http://` 与 `https://` 协议链接，防止潜在的本地文件协议或恶意伪协议执行风险。
- **前端智能防抖与错误降级处理**：
  - 在 [api.ts](file:///e:/Developer%20Tool/Bobapi%20Tool/src/lib/api.ts) 中封装统一的 `openUrl(url: string)` 辅助函数，内置 800ms 防抖去重机制，防止用户快速双击链接时在浏览器中重复弹出两个相同标签页。
  - 当外部系统异常导致唤起失败时，自动通过 `sonner` 气泡轻弹窗给予精准友好的错误提示。
- **全局链接无感自动拦截捕获**：
  - 在 [App.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/App.tsx) 挂载根级捕获监听器，自动捕获全应用内所有带有 `target="_blank"` 或跨源指向外部 Web 的超链接点击，统一无缝转由系统默认浏览器打开。
- **重点功能模块全链路集成**：
  - **快捷工具箱 ([QuickToolsModal.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/components/QuickToolsModal.tsx))**：BobAPI 官方网站（`https://bob-api.com`）与 TaijiAI 备用专线（`https://taijiai.online`）外链均无缝唤起默认浏览器，并补充了精准 Tooltip 与按压缩放微动效。
  - **强制更新与版本检查弹窗 ([ForceUpdateModal.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/components/ForceUpdateModal.tsx))**：直接下载模式与自动更新回退模式下的“前往 GitHub 下载”按钮全面接入 `openUrl`，确保用户更新下载体验顺畅无阻。

### 4. 细节微交互与动效增强
- **网络状态在线呼吸扩散光环**：
  - 在 [App.tsx](file:///e:/Developer%20Tool/Bobapi%20Tool/src/App.tsx) 的网络状态检测条中，当网络状态为 `reachable`（连通良好）时，在绿色 `Wifi` 图标周围新增平滑扩散波纹（`animate-ping` 呼吸光晕），生动反馈当前官方节点心跳连通状况。
- **交互光标与无障碍提示补齐**：
  - 统一为所有操作按钮、外部链接卡片规范设置 `cursor-pointer` 与交互 hover/active 态，避免误触与视觉不明确。
