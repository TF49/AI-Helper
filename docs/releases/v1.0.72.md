## 🔐 Accio 本地网关鉴权重构

### 🛣️ 路径凭据鉴权

- 🧩 **凭据随路径传递**：Accio 只读取 `GATEWAY_BASE_URL` 与 `ADK_BASE_URL`，且以字符串拼接的方式生成请求地址，因此实例凭据改为写入路径前缀：`/i/<token>` 📎
- 🛡️ **先验后路由**：安全中间件包裹在路由外层，先用常量时间比较校验凭据，通过后再剥离前缀进入路由，业务逻辑和官方转发都看不到凭据 🔒
- 🔁 **请求头兼容**：`x-ai-helper-instance` 与 `x-gateway-auth` 请求头仍可用，方便其他调用方继续使用 🤝

### 🔑 实例凭据生命周期

- ♻️ **改端口不失效**：Bridge 停止或改端口重启时，凭据保持不变，已拉起的 Accio 无需重启 ✅
- 🚪 **退出即失效**：AI Helper 退出后凭据作废，重新打开时会生成新凭据 🔄

### 🛡️ 防官方泄露：放行账号元数据接口

- 📋 **元数据白名单**：开启 `prevent_official_leak` 后，登录态、团队、Agent 同步、技能、插件、功能开关、模型目录等接口仍可透传，Accio 才能正常运行 🧭
- 💰 **计费路径照旧拦截**：推理、Embedding、生图、MCP 等路径由 Bridge 本地接管，不在白名单内的路径一律拒绝 🚫
- 🧼 **路径严格校验**：只接受字母、数字、`/`、`-`、`_`，拒绝 `..` 和百分号编码，防止 URL 规范化把请求改写到计费接口 🧱

## 🖼️ Cursor 多模态图片安全加固

### 🚨 安全漏洞修复

- 🗂️ **路径遍历防护**：新增 `safe_read_local_image()`，统一完成路径规范化、符号链接检测和白名单校验 🛑
- 📏 **Base64 DoS 防护**：解码前先检查编码长度，超大字符串不会再绕过内存限制 💣➡️🧯
- ⏱️ **TOCTOU 竞态防护**：读取前后检查文件元数据，并校验普通文件类型 📄✅

### 🪟 跨平台路径兼容

- 🔤 **路径统一规范化**：比较白名单目录前执行 `canonicalize`，解决 Windows `\\?\` 前缀、8.3 短路径名和 macOS `/var` 软链接导致的误判 🍎🪟
- 💿 **file:/// 盘符处理**：Windows 下的 `file:///` 地址可正确解析盘符 ✔️

### 🧹 代码质量

- ♻️ **重复代码合并**：提取 `build_openai_multimodal_content()`，减少约一半的重复代码 🧩
- 📝 **日志更详细**：图片格式识别失败、路径安全检查失败都会输出具体原因 🔍
- 🧹 **Clippy 清零**：修复 CI 中的 clippy 报错，`cargo check` 与 `cargo clippy` 均无警告 ✨

## 🖥️ 监控后台：管理员账号密码登录

- 🔑 **账号密码登录**：监控后台支持用户名和密码登录，账号默认 `admin`，可通过 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD` 环境变量修改 👤
- 🎟️ **Session 鉴权**：登录后签发 HMAC 签名的 Session Token，有效期内有效，可用于后续请求 ⏳
- 🚫 **注销黑名单**：退出登录后 Token 立即进入黑名单，无法再次使用 🧊
- 🔁 **静态 Token 兼容**：原有 `ADMIN_TOKEN` 仍可用于脚本自动化维护 🤖
- 🛑 **登录限流**：登录接口启用限流，降低暴力破解风险 🧱
- 📊 **诊断页登录界面**：`diagnostics.html` 新增登录弹窗和登录态组件，与后端鉴权保持一致 🩺
