## 🌟 核心升级亮点 (Core Highlights) 💡✨💎💬🐞

### 1. 💬 全新意见反馈弹窗：`FeedbackModal` —— 三类工单 · 智能模板 · 多入口触发 🐞💡❓✨

过去想反馈 BUG 或提建议，往往要自己整理版本号、系统环境、当前在配哪个 Agent，再去找群 / 提 Issue，信息容易丢、复现难对齐。😫  
**v1.0.64 正式落地 [`FeedbackModal.tsx`](file:///e:/Developer%20Tool/AI%20Helper/src/components/FeedbackModal.tsx)！** 🎉🎨

```
+-----------------------------------------------------------------------------------+
|            💬 意见反馈提交流程 (Feedback Pipeline)                                  |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  🖱️ 点击「反馈」入口（标题栏 / 用户菜单等）                                        |
|         │                                                                         |
|         ▼                                                                         |
|  🖥️ 拉取真实系统诊断信息 (get_system_diagnostic_info)                              |
|         │                                                                         |
|         ▼                                                                         |
|  🐞 / 💡 / ❓ 选择反馈类型 → 自动切换预填模板                                      |
|         │                                                                         |
|         ▼                                                                         |
|  📧 填写联系邮箱（必填，校验格式，记住本地）                                       |
|  📝 补充复现步骤 / 建议细节                                                        |
|         │                                                                         |
|         ├── 📋「仅复制内容」→ 格式化全文进剪贴板                                   |

|                    ├── ✅ 飞书成功 → Toast 感谢并关闭弹窗 🎉                        |

```

### 2. 🛰️ 飞书互动卡片双通道：自建应用机器人优先 · Webhook 自定义机器人兜底 🤖📨✨

反馈不再停在客户端本地，而是结构化推送到开发团队飞书群！  
**v1.0.64 新增独立模块 [`feedback.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/feedback.rs)，并注册 Tauri 命令 `submit_feishu_feedback` / `get_system_diagnostic_info`！** 🔌🎉

```
+-----------------------------------------------------------------------------------+
|            🛰️ 飞书推送优先级 (Feishu Dual Channel)                                  |
+-----------------------------------------------------------------------------------+
|                                                                                   |
|  凭据解析优先级：请求参数 → 运行期环境变量 → 编译期 option_env! 注入                 |
|         │                                                                         |
|         ▼                                                                         |
|  🥇 模式 1：App ID + App Secret + Chat ID 齐全？                                   |
|         ├── 获取 tenant_access_token                                              |

|         │                                                                         |
|         ▼（否则）                                                                  |

|                                                                                   |

```

#### 🎨 卡片里一屏看清现场
互动卡片自动带上：
- 反馈类型徽章、联系邮箱、客户端版本、系统环境；  
- 当前配置目标（Claude Code / WorkBuddy / Accio Work / ChatGPT Codex / 应用与 CLI 路径）；  
- 登录用户、官方网络状态、提交时间戳与正文详情！📊👀

#### ⏱️ 网络超时友好
- HTTP 客户端超时 **12 秒**，避免弱网下界面长时间卡住；  
- Token / 发消息失败会返回可读中文原因（权限、凭证、机器人未入群等）！🛡️💬

---

### 3. 🖥️ 系统诊断一键带上：真实 OS 长版本名 + CPU 架构 🧰🔍✨

不再让用户手填「Windows 啥版本」。  
**`get_system_diagnostic_info`** 基于 `sysinfo` 读取长系统版本名（失败则回落短名 / `std::env::consts::OS`），并拼接架构，例如：

> `Windows 11 Pro (x86_64)` 🪟💻

弹窗打开时自动拉取并写入模板；若命令失败，再回落 `navigator.platform`，保证模板永远有环境底稿！🛟✨

---

### 4. 📋 提交失败剪贴板兜底：反馈永不丢失 🛟💎✨

无论是飞书认证失败、Webhook 异常，还是本地未配置任何飞书环境变量：

1. 后端返回明确失败原因；  
2. 前端 **自动把格式化反馈全文写入剪贴板**；  
3. Toast 提示「已复制，可手动转发」，时长更长方便看清！  

另提供「仅复制内容」按钮，方便用户主动导出、粘贴到 Issue / 社群。📋✅

---

### 5. 🔐 编译期 `.env` 安全注入：飞书凭据不进仓库、打包自动带上 🛡️🔑✨

[`build.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/build.rs) 增强：

- 自动加载 **项目根目录 `.env`** 与 **`src-tauri/.env`**；  
- 将 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` / `FEISHU_CHAT_ID` / `FEISHU_WEBHOOK_URL` 以 `cargo:rustc-env` 注入；  
- 运行时仍可用环境变量覆盖；请求参数优先级最高；  
- 仓库仅提供 [`.env.example`](file:///e:/Developer%20Tool/AI%20Helper/.env.example) 模板，真实凭据留在本机，规避 Git 泄露！🚫🔓
