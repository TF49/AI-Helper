# AI Helper v1.0.15

**发布日期**: 2026-09-24

AI Helper v1.0.15 重点聚焦于**桌面大屏视窗与全屏体验的深度重构（Full-Screen Responsive Canvas）**。针对此前版本在宽屏或窗口最大化状态下，右侧主配置展台受限于固定宽度约束、且内容过于紧凑聚集在上半部、底部与右侧产生大面积空间留白的问题，本版本实施了彻底的**视口全屏自适应与弹性栅格体系升级**。移除了人为的宽度限制，打通了全链路的纵向 Flex 弹性伸缩继承，让网关节点选择、配置文件路径、认证凭据与测试模型四大核心卡片在垂直与水平方向自然铺满、等高对称分布，在保持小窗自适应平滑滚动的同时，赋予大屏工作台极致饱满、现代与通透的视觉体验。

---

## 🚀 核心更新

### 1. 右侧主工作台全屏自适应布局（Canvas Full-Screen Responsive Layout）
彻底告别内容局限在固定宽度与顶部拥挤的设计，全面释放桌面工作台的空间张力：
- **移除宽度瓶颈限制**：
  - 在 [App.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/App.tsx) 中移除了原有的 `max-w-6xl mx-auto` 视口宽度硬性约束，右侧主工作台容器采用全宽 `w-full` 自适应流动布局。在大屏显示器或窗口最大化状态下，配置展台可自适应延展并完全占满右侧全部可用视区，消除右侧不必要的空白边距。
- **打通纵向全屏弹性高度继承链**：
  - 重构了从 `<main>` 主区域 $\rightarrow$ 视口容器 $\rightarrow$ `motion.div` 切页动效容器 $\rightarrow$ 配置面板根节点的 Flex 弹性高度链路（`h-full flex flex-col flex-1 min-h-0`）。
  - 配置面板内部采用纵向空间两极锚定设计（`justify-between`）：顶部专属标题栏固定置顶（`flex-shrink-0`），底部「保存并应用配置」操作栏固定置底（`flex-shrink-0`），彻底消除了原先卡片下方的空旷留白。

### 2. 2×2 核心配置卡片纵向均分与对齐优化（Balanced 2×2 Card Grid）
在 [ChatGPTPanel.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/ChatGPTPanel.tsx) 与 [ClaudePanel.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/ClaudePanel.tsx) 中重构了双列栅格的垂直空间分配机制：
- **卡片两两垂直等高延展**：
  - 左右两列（基础设施列与模型凭据列）均配置为 `flex-1 min-h-0` 独立弹性容器，使「API 服务网关节点」与「OpenAI API Key / Anthropic Token」两张首排卡片等高对称对齐；
  - 下排的「本地配置文件路径」与「测试模型及推荐芯片」两张卡片同样自适应延展并等高对齐，四大卡片整体铺满中段主视区，视觉比例极为规整均衡。
- **完善小屏幕/缩放场景的兼容性**：
  - 各核心卡片设定 `min-h-[160px]` 最小高度保护，同时父级 `<main>` 容器保留平滑的 `overflow-y-auto` 纵向滚动能力。当用户将窗口缩放到较小尺寸（如高度 600px）时，内容绝不发生挤压穿透或元素遮挡，依旧可以流畅向下滚动操作。

### 3. 卡片内部排版呼吸感与细节增强（Card Content & Details Refinement）
针对卡片延展后的内部空间，对各个输入与展示组件进行了细节优化与语义充实：
- **节点卡片选择器自适应伸展（NodeCardSelector）**：
  - [NodeCardSelector.tsx](file:///e:/Developer%20Tool/AI%20Helper/src/components/NodeCardSelector.tsx) 新增 `className` 属性支持并升级按钮容器为 `h-full flex flex-col justify-between`。无论在标准窗口还是超宽全屏下，节点卡片顶部的图标名称标签与底部的专线说明及 URL 均能自然拉开间距、两端对齐，呈现出如云服务控制台般的专业卡片质感。
- **认证凭证安全提示卡片（Security Guarantee Hint）**：
  - 在 API Key 输入框下方，新增了配有盾牌图标（`ShieldCheck`）的安全通信与存储保障说明条，明确告知凭据仅加密储存于本地配置文件与当前环境变量中，直接与所选反代专线建立通信，绝不经过任何第三方服务器中转，在充实卡片下半部空间的同时增强用户信任感。
- **本地配置文件管理与状态指引**：
  - 当检测到配置文件存在时，展示清晰规整的绿色加载状态与自动生效说明，与右侧的模型推荐芯片卡片高度自然契合。
- **常用热门模型推荐芯片样式优化**：
  - 推荐芯片区域独立划分为卡片底部快捷工具栏，采用上边框微分割线与等宽字体，支持一键点击直接注入模型输入框。

### 4. ChatGPT (Codex) 与 Claude Code 双面板一致性对齐
- 对 ChatGPT (Codex) 面板与 Claude Code 终端面板进行了 1:1 规范对齐，科技蓝（Blue）与优雅紫（Purple）两套主题色在全新的全屏饱满布局下保持一致的高水准交互体验。
