## 🚀 详细更新亮点

### 1. 🛠️🗄️ 行业首创：Trae Work (TRAE SOLO CN) 专属面板与 SQLite 全局状态库穿透引擎

#### 📉 痛点背景
作为字节跳动针对个人开发者与团队打造的 AI 原生 IDE，**Trae (TRAE SOLO CN)** 具备极高的代码理解与全自动 Agent 编程能力。然而，用户在配置第三方大模型接口（如 Bob API、各类中转接口或私有自建模型）时面临极大困扰 😣：
1. 界面入口层级极深，需要在「设置 ➔ 模型管理 ➔ 自定义模型」中逐条录入；
2. 配置参数繁多，且在 Solo Work、Solo Agent、Solo Coder、Solo Design 等不同智能体工作场景下无法快速统一生效；
3. Trae 并不使用传统的 JSON/TOML 纯文本配置文件，而是将模型配置持久化在 SQLite 全局状态数据库 `state.vscdb` 中，普通用户完全无法通过文件复制或脚本快速部署 🤯。

#### 🔬 核心技术落地：Rust `rusqlite` 底层数据库穿透
AI Helper 后端引入高性能 `rusqlite` (bundled 特性)，直接连通并穿透读写 Trae Work 的全局 SQLite 状态库 🗄️⚡：

```rust
// 🗄️ src-tauri/src/traework.rs 核心数据库读写架构
pub fn traework_db_path() -> Result<PathBuf, AppError> {
    #[cfg(target_os = "windows")]
    {
        if let Ok(appdata) = std::env::var("APPDATA") {
            let base = PathBuf::from(&appdata);
            let candidates = [
                base.join("TRAE SOLO CN").join("User").join("globalStorage").join("state.vscdb"),
                base.join("TRAE SOLO").join("User").join("globalStorage").join("state.vscdb"),
                base.join("Trae CN").join("User").join("globalStorage").join("state.vscdb"),
                base.join("Trae").join("User").join("globalStorage").join("state.vscdb"),
                base.join("TraeWork CN").join("User").join("globalStorage").join("state.vscdb"),
                base.join("TraeWork").join("User").join("globalStorage").join("state.vscdb"),
            ];
            for cand in &candidates {
                if cand.exists() {
                    return Ok(cand.clone());
                }
            }
            return Ok(candidates[0].clone());
        }
    }
    // ... macOS 与 Linux 降级探测
}
```

#### 🛡️ 六大高可用与安全保障设计：
1. **防锁超时机制 (`busy_timeout: 5s`)** ⏱️：Trae 客户端处于打开状态时可能持有 SQLite 独占锁，AI Helper 设定 5 秒智能重试超时，杜绝 `database is locked` 异常；
2. **多账号与动态 UID 智能捕获** 👤：自动解析 `ItemTable` 中以数字 UID 为前缀的 `AI.agent.model.model_list_map` 键名，精准识别当前已登录的主账号环境；
3. **9 大核心分类全场景增量合并** 🧩：自动将新模型同时同步至：
   - `solo_work_lite` 💼
   - `solo_agent_lite` 🤖
   - `solo_coder` 💻
   - `solo_design_lite` 🎨
   - `solo_work_remote` 🌐
   - `solo_agent_remote` 📡
   - `solo_design_remote` 🖼️
   - `assistant` 🤝
   - `agent` 🚀
4. **模型开箱即用自动激活 (`recent_user_selection_by_agent_label`)** 🎯：配置写入后，同步更新最近激活模型标记，让开发者打开 Trae 时无需在下拉列表中手动切换，立即生效！
5. **凭据安全脱敏与防覆盖保护** 🔒：若用户二次修改配置且未重新输入 API Key，算法智能提取数据库内原有 `ak` 与 `custom_model_id` 进行保真复用，绝不造成密文遗失或覆盖；
6. **已存模型管理与安全删除 (`delete_traework_model`)** 🗑️：主面板卡片支持查看当前配置库内的所有自定义模型，点击垃圾桶图标即可在数据库各分类中安全剔除，保持数据库洁净清爽！

### 2. 🎛️🧠 三协议无缝兼容与极客级超参调优矩阵

#### 🌐 全协议全格式自适应切换
针对不同大模型中转站与协议标准，Trae Work 面板提供了极具针对性的三大协议切换器 🔄⚡：

| 协议格式选项 | 典型请求端点 | 适用模型/场景 | 特色行为 |
| :--- | :--- | :--- | :--- |
| **OpenAI Responses API** ⚡ | `https://bob-api.com/v1/responses` | `gpt-5.6-sol`, Bob 专线 | 智能追加 `/responses`，全面兼容最新高吞吐推理规范 |
| **OpenAI Chat Completions** 🤖 | `https://api.openai.com/v1/chat/completions` | `gpt-4o`, `deepseek-v3.1` | 经典标准化格式，自动补齐 `/chat/completions` |
| **Anthropic Messages** 🧠 | `https://api.anthropic.com/v1/messages` | `claude-sonnet-4-5`, `claude-opus-4-5` | 专为 Claude 系列设计的原生 Messages 格式，自动补齐 `/v1/messages` |

- **「完整 URL」模式自由切换** 🔀：当用户关闭该模式时，输入基础域名（如 `https://bob-api.com/v1`），系统将根据所选协议自动追加对应后缀，新手老手均能自如掌控！

#### 🎛️ 深度超参数微调矩阵 (Advanced Configuration)
点击「高级参数配置」折叠栏，即可开启专业级开发调参空间 🛠️🎚️：
- 🖼️ **多模态视觉理解开关 (`supports_images` / `multimodal`)**：一键开启图片上传、代码截图识别能力；
- 💡 **深度思考模式三态开关 (`thinking_mode`)**：
  - `默认 (Default)`：遵循模型自身预设；
  - `强制开启 (On)`：强制要求模型输出 `<thought>` 链式思考过程；
  - `强制关闭 (Off)`：追求极致出词速度，跳过思考链；
- 🔄 **最大对话与思考轮数 (`max_turn`)**：支持 1 到 1000 轮灵活调节，默认贴心预设 500 轮，满足大型复杂工程连续 Coding 需求；
- 📊 **细粒度上下文 Token 胶囊矩阵**：
  - **Prompt 输入限制**：提供 `128k`、`256k`、`512k`、`1M` 一键预设胶囊 📦；
  - **单次生成输出限制**：提供 `4k`、`16k`、`32k`、`128k` 常用档位 🚀；
- 🎯 **采样参数精雕细琢**：自由设定 `Temperature` (0.0~2.0)、`Top-P` (0.0~1.0) 与 `Top-K`，打造符合个人编码习惯的模型个性！

### 4. 🧭⚡ 全维度系统路径多级深潜探测与进程调度

#### 🔍 跨平台六重智能路径探测网络 (`app_paths.rs`)

1. **用户已存偏好优先**：优先读取用户在 `~/.ai-helper/app_paths.json` 中保存的个性化路径；
2. **正在运行的进程树捕获** 🌲：通过 `sysinfo` 单次扫描系统进程树，精准抓取正在运行的 `TRAE SOLO CN.exe` 或 `Trae.exe` 的绝对二进制路径；
3. **Windows 注册表反向解析** 📜：穿透查询 `HKCU` 与 `HKLM` 下的 `Uninstall` 卸载注册表项，提取 `DisplayIcon` 与 `InstallLocation`；
4. **多盘符开发工具标准目录遍历** 💾：深度巡检 E、C、D、F 盘的 `Developer Tool\TRAE SOLO CN`、`Developer Tools` 等开发者常见自定义部署目录；
5. **系统与用户标准安装目录探测** 📁：
   - Windows: `%LOCALAPPDATA%\Programs\TRAE SOLO CN\TRAE SOLO CN.exe` 与 `Program Files`；
   - macOS: `/Applications/Trae.app/Contents/MacOS/Trae` 与 `/Applications/TRAE SOLO.app` 🍏；
6. **系统环境变量 PATH 兜底扫描** 🌐：智能检索全局环境变量中注册的 `trae` 与 `traework` 指令。

## 💡 升级指南与快速上手 (Quick Start)

### 30 秒玩转 Trae Work 自定义模型
1. 启动 **AI Helper v1.0.30**，左侧导航栏点击全新的 **Trae Work** 选项卡 🔵；
2. 填入你的服务地址（默认推荐 `https://bob-api.com/v1/responses`）、API Key 与模型名称（如 `gpt-5.6-sol`）🔑；
3. 点击 **「测试连接并保存配置」** 🚀：
   - 拟真终端将自动发起协议握手测试；
   - 看到 `HTTP 200 OK` 后，系统会自动将配置增量写入 Trae 的 `state.vscdb` 数据库；
4. 点击右下角 **「启动 Trae Work 客户端」**（若已在运行则点击 **「重启 Trae Work 客户端」**）⚡；
5. 进入 Trae Work，新建任意工作区，你配置的模型已经在模型列表中就绪，即刻开启全自动 Agent 编程新体验！🎉🤖💻✨
