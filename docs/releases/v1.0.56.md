### 3. 🔍 全环境智能探测体系：macOS 级 Homebrew / NVM 多版本扫描与终端调度 🤖⚡

为了让各 AI Agent（Claude Code、Codex CLI、ChatGPT、WorkBuddy、Accio Work）在 macOS 下真正做到“开箱即用、一键拉起”，后端探测与调度内核实现全量升级：

#### 🛠️ 1. macOS 核心路径与多环境深度探测引擎 (`app_paths.rs`) 🔎
- 🍺 **Homebrew 智能支持**：自动覆盖 Apple Silicon 专用的 `/opt/homebrew/bin` 以及 Intel 专用的 `/usr/local/bin`；
- 📦 **NPM 全局与包管理器扫描**：覆盖 `~/.npm-global/bin`、`~/.local/bin`、`~/.bun/bin` 与 `~/.cargo/bin`；
- 🌟 **NVM 多版本 Node 智能识别与倒序优选**：
  ```rust
  // 探测 NVM 默认或多版本 node 目录
  let nvm_versions = home.join(".nvm/versions/node");
  if nvm_versions.exists() {
      if let Ok(entries) = std::fs::read_dir(nvm_versions) {
          let mut v_dirs: Vec<PathBuf> = ...;
          v_dirs.sort();
          v_dirs.reverse(); // 优先选用最新版本 node
          search_dirs.extend(v_dirs);
      }
  }
  ```
  自动遍历并优先绑定最新版本的 Node 运行时，告别 Mac 开发者因 NVM 环境变量隔离导致 CLI 工具探测不到的烦恼！
- 📂 **原生应用探查**：智能检索 `/Applications/ChatGPT.app` 与 `~/Applications/ChatGPT.app`；
- 🗂️ **原生 AppleScript 文件选择器**：通过 `choose file with prompt` 调用 macOS 专属文件选择对话框，无第三方依赖，纯净高效！

#### 💻 2. AppleScript 独立终端窗口与命令调度 (`process_manager.rs`) 🚀
- ⌨️ 在 [`src-tauri/src/process_manager.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/process_manager.rs) 中，调度 **Claude Code CLI** 与 **Codex CLI (`--no-daemon`)** 时，通过 `osascript` 唤起 Mac 原生 Terminal.app 并开启独立 Tab 窗口执行，环境隔离不锁死！
- 🌐 唤起 **Accio Work** 客户端时，自动注入环境变量 `GATEWAY_BASE_URL="http://127.0.0.1:{bridge_port}"`，让本地 Bridge 网关在 Mac 上同样提供毫秒级热代理守护！

### 4. 🛡️ 网络韧性与拦截防御：HTML 熔断拦截识别 + 代理探测 TTL 高并发缓存 ⚡🌐

在严苛网络环境或受限局域网中，接口常会遭遇企业防火墙、安全网关拦截或 CDN 挑战。v1.0.56 对网络容灾与诊断体系进行了立体式加固：

```
+-----------------------------------------------------------------------------------+
|                           🛡️ 网络请求防护与代理感知链路                            |
+-----------------------------------------------------------------------------------+
|  [客户端发起请求]                                                                  |
|         │                                                                         |
|         ▼                                                                         |
|  [上游代理快速检测] ──> ⚡ 命中 PROXY_CACHE (3s TTL 极速放行，免重复 TCP 握手探测)  |
|         │                                                                         |
|         ▼                                                                         |
|  [服务端响应捕获] ──> 🔍 parse_api_response_body 智能防护                         |
|         ├─ 若状态正常且为标准 JSON ────> 🟢 正常解析业务数据                      |
|         ├─ 若被拦截返回 HTML (以 '<' 开头) ─> 🛑 触发熔断保护，抛出 TUN 代理指引    |
|         └─ 若超时或连接失败 ───────────> 💡 精准提示开启代理 / TUN 虚拟网卡模式    |
+-----------------------------------------------------------------------------------+
```

#### 🛑 1. 防火墙 / Cloudflare HTML 拦截熔断识别 (`auth.rs`) 🛡️
- ⚠️ **旧版痛点**：若遇到企业防火墙、校园网认证页面或 CDN 防护返回 HTML 页面，底层直接反序列化为 JSON 会报错令人困惑的 `expected value at line 1 column 1`；
- 🚀 **新版防护**：在 [`src-tauri/src/auth.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/auth.rs) 中新增 `parse_api_response_body`：
  ```rust
  let trimmed = text.trim();
  if trimmed.starts_with('<') {
      return Err(format!(
          "{action_name}遇到网络拦截 (收到 HTML 页面，HTTP {})，请检查网络或开启代理 / VPN 的 TUN 模式重试",
          status.as_u16()
      ));
  }
  ```
  一针见血指明拦截原因，杜绝冷冰冰的技术乱码！

#### ⚡ 2. 上游代理探测 3 秒 TTL 轻量级互斥缓存 (`updater.rs`) 🏎️
- 🔍 在 [`src-tauri/src/updater.rs`](file:///e:/Developer%20Tool/AI%20Helper/src-tauri/src/updater.rs) 中引入 `PROXY_CACHE` 缓存机制；
- 避免在用户高频触发 API 请求、多渠道状态轮询时重复进行底层 TCP 端口握手探测，减少 CPU 与网络开销，请求响应速度大幅提升！

#### 💡 3. 网络连通性超时诊断话术升级 (`network.rs`) 🌐
- 超时与 DNS 解析异常错误提示同步强化，明确提示开启代理或 VPN 的 TUN 虚拟网卡模式，引导一步到位！
