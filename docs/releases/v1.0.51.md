## 🌟 核心升级亮点 💡✨

### 1. 🍎 全配置面板底部操作栏升级：苹果风毛玻璃悬浮 Dock 栏（Apple-Style Floating Dock Bar）✨🪟

告别过去传统单调的「底部贴边直角分割栏」，全面引入极具视觉呼吸感的**悬浮式毛玻璃 Dock 胶囊**！这一设计全面覆盖系统内所有 **5 大核心配置面板**：
- 🟦 **`ChatGPTPanel`**（OpenAI Codex CLI 面板）
- 🟣 **`ClaudePanel`**（Anthropic Claude Code CLI 面板）
- 🟩 **`WorkbuddyPanel`**（WorkBuddy AI 面板）
- 🟠 **`AccioWorkPanel`**（Accio Work 面板）
- 🩵 **`AppPathsPanel`**（应用与 CLI 路径面板）

#### 🔮 质感进化细节全解析：
- 🪐 **灵动悬浮胶囊形态**：不再使用生硬贴地的 `border-t` 横线，改为 `rounded-2xl` 悬浮药丸形态，四周留白透气，视觉重心自然聚焦在操作中枢；
- 🪟 **高级苹果风双重滤镜**：
  - 半透明晶莹底色：`bg-white/45 dark:bg-[#0c0e18]/45`；
  - 极佳超清毛玻璃扩散：`backdrop-blur-xl`；
  - 饱和度增强：`backdrop-saturate-150`，透出背部流光与内容，富有浓郁的 macOS / iOS 现代工业设计质感；
- 💡 **双层微高光立体拟物阴影**：
  - 亮色模式：`shadow-[0_4px_24px_-2px_rgba(0,0,0,0.06),inset_0_1px_1px_0_rgba(255,255,255,0.7)]`；
  - 暗黑模式：`dark:shadow-[0_4px_24px_-2px_rgba(0,0,0,0.3),inset_0_1px_1px_0_rgba(255,255,255,0.08)]`；
  - 顶部细腻的内嵌高光线条（Inner Highlight），如同精雕细琢的高透水晶玻璃切面；
- 🔘 **辅助按钮与状态指示全面升华**：
  - 左侧辅助按钮（如「重新配置向导」等）换装微毛玻璃外衣 `bg-white/60 hover:bg-white/90 backdrop-blur-xs border-white/80 dark:border-white/10`，触感温润灵动；
  - 状态指示与步进文字优化为 `font-medium text-slate-500 dark:text-gray-400`，字阶对比更清晰，视觉层次一目了然。

### 2. 🧭 侧边栏导航架构深度重构：层级降维与心智减负（Sidebar Hierarchy Optimization）🗂️📐

我们重新审视了主界面侧边栏的信息架构，消除了以往版本中的认知歧义：

- 🚀 **功能模块逻辑归位**：
  - **修改前**：`应用与 CLI 路径 (app_paths.json)` 混在「Agent 客户端配置」列表中，与各大 AI Agent（Codex、Claude、WorkBuddy、Accio）并列，混淆了「AI 对话客户端」与「系统底层环境路径」的概念；
  - **修改后**：将「应用与 CLI 路径」移动至「快捷工具与辅助」模块，与「环境初始化向导 (`InitializationModal`)」和「快速诊断工具箱 (`ToolsDrawer`)」统一收纳，逻辑关系清晰分明；
- 🎨 **视觉规格统一规范化**：
  - 按钮样式采用规范的紧凑型辅助组件外观（图标容器 `w-6 h-6 rounded-md`，内边距 `px-2.5 py-2`），与诊断工具箱完全对齐；
  - 选中状态保持青绿色（`teal-500`）高亮与主题边框，平滑切换；
- 🎯 **聚焦核心 Agent 体验**：
  - 使得「Agent 客户端配置」区域更加纯粹聚焦于四大 AI 工具，减少视觉噪声，极大降低新用户的上手与理解成本！

### 3. 🧹 自动化分发镜像脚本轻量化：存储自动清理与避峰调度（Sync-Mirror Auto-Cleanup）⚡📦

国内自托管分发节点的同步脚本 `scripts/sync-mirror.sh` 迎来重要自动化升级：

- 🗑️ **单版本纯净保留策略 (`cleanup_old_versions`)**：
  - 每次执行同步拉取最新版本时，脚本会自动检测下载目录；
  - 自动匹配并彻底清理所有非当前版本 Tag 的旧版安装包（`AI-Helper-v*-Windows-x64-*`）；
  - 只保留最新的 `Setup.exe` 与绿色便携版 `Standalone.zip`，杜绝多版本镜像长期累积导致的服务器磁盘空间耗尽风险；
- ⏰ **Cron 定时调度智能避峰**：
  - 优化推荐定时任务执行策略（`3-59/10 * * * *`），避开整点网络高峰，保障分发节点与主仓库之间同步的稳定与流畅；
- 🛡️ **幂等检测保障**：
  - 即便当前已经是最新版本无需下载，依然会自动执行冗余文件清理，始终保持服务器分发目录干净如初！
