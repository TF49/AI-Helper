## 📸 自定义头像：让账号更有辨识度 🎨🪄

### ⬆️ 上传、更换，只需点击头像

登录后，在侧边栏底部打开用户菜单，或进入个人中心，点击头像即可选择图片 🖱️🖼️。上传时会出现处理中状态 ⏳，完成后会立即更新应用中展示的头像 ✅。

- 🗂️ 支持选择 PNG、JPG/JPEG、WEBP 和 GIF 图片
- 📏 原始图片最大为 **10 MB**；超过限制时会提示重新选择
- ✂️ 自动从图片中央裁出正方形，适配圆形头像展示
- 🧮 输出缩放至 **256 × 256**，并进行图片压缩，减少存储空间
- 🛟 优先保存为 WebP；当前环境不支持时自动回退到 JPEG
- 🧑‍💻 没有自定义头像时，中文名称显示首字，英文名称显示前两个字符
- 🔢 纯数字账号使用用户图标作为默认头像，避免数字头像难以辨认

### 🧹 移除头像，恢复默认样式

设置过自定义头像后，个人中心头像旁会出现“移除头像”入口 🗑️。点击后会删除该账号在本机保存的自定义头像，并立即恢复默认头像样式 🔄🙂。

### 🔐 隐私与保存说明

- 💻 自定义头像只保存在当前设备的本地浏览器存储中，不会上传至服务器或账号资料
- 🪪 头像按账号 ID 分别保存；切换账号时会显示对应账号的头像
- 📦 重装、清理应用数据或更换设备后，本地头像可能需要重新设置
- 🚪 未登录时不可上传头像；登录后设置的头像会与该账号关联

## ❓ 常见问题 FAQ 🧭💬

### 头像会同步到我的账号或其他设备吗？ ☁️

不会。头像保存在当前设备的本地存储中，并按账号 ID 区分；它不会上传到 bob-api.com，也不会自动同步到其他设备 💻🔒。

### 为什么上传后头像不是动图？ 🌀

上传图片会被裁剪并压缩为适合头像展示的正方形图片。即使选择 GIF，保存后也是处理后的静态头像帧 🖼️。

### 上传后没有看到头像变化怎么办？ 🔍

确认当前已登录目标账号，再检查选择的图片格式是否受支持、文件是否小于 10 MB 📋。上传成功后，头像会在侧边栏和个人中心自动刷新 🔄✅。

### 移除头像会影响账号资料吗？ 🪪

不会。移除操作只会删除本机保存的自定义头像，账号登录信息及服务器上的资料不会因此改变 🧹🛡️。
