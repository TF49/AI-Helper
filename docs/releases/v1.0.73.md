## 🛡️ 更新系统：毫秒级防缓存穿透与高版本验签穿透 🔄🚀

### ⏱️ 毫秒级防缓存穿透机制
- 🚫 **时间戳动态注入**：在拉取更新清单文件 (`updater.json`)、公钥签名 (`.sig`) 及权威 `SHA256SUMS` 校验清单时，请求 URL 自动追加 `_t={timestamp_ms}` 毫秒级时间戳防缓存参数 🕒。
- 🛑 **强制作废 HTTP 缓存**：请求头显式注入 `Cache-Control: no-cache, no-store, max-age=0` 与 `Pragma: no-cache`，彻底粉碎公网 CDN 与浏览器代理的脏缓存阻碍 🧼。

### ⚖️ 高版本公钥验签镜像信任放行
- 🔐 **公钥签名验签穿透**：当 GitHub 官方直连由于全球 CDN 节点缓存同步延迟报告「暂无更新」时，若加速镜像源（如 ghfast）提供了更高版本且**成功通过本地公钥 Ed25519 签名验证**，更新引擎将智能采纳并放行该可信版本 🌟。
- 🛡️ **严格防回滚与同平台约束**：依然保持严格的版本递增比较与目标平台二进制匹配，既确保更新即时性，又守住代码签名的安全底线 🔒。

### 🌐 校验清单解析防污染
- 📋 严格校验 `SHA256SUMS` 中是否包含当前目标版本标识（`AI-Helper-vX.Y.Z`），防止跨版本校验清单误用 🛡️。

## 🔍 路径探测：Windows 商店版与 macOS Spotlight 全域定位 💻🍎

### 🪟 Windows 微软商店版 ChatGPT 秒级定位
- 📑 **用户注册表无权限扫描**：优先遍历当前用户 AppModel 注册表项 (`HKCU\Software\Classes\Local Settings\Software\Microsoft\Windows\CurrentVersion\AppModel\Repository\Packages`)，无需管理员特权即可毫秒级精确定位 `OpenAI.Codex` 的安装目录 ⚡。
- 🔢 **智能版本排序取优**：当存在应用更新残留目录时，自动按版本号降序排序，确保始终绑定最新版本的 `ChatGPT.exe` 🎯。
- 🛠️ **PowerShell 稳健兜底**：注册表受限场景下自动平滑回退至 `Get-AppxPackage OpenAI.Codex` 探测 🛡️。

### 🍏 macOS Spotlight 深度探测
- 🔍 **官方 Bundle ID 智能检索**：在标准 `/Applications` 之外，利用 macOS Spotlight 引擎 (`mdfind kMDItemCFBundleIdentifier == 'com.openai.chat'`) 检索非标准目录下安装的 ChatGPT 客户端，实现即装即测 🍏。
