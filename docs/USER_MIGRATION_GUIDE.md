# AI Helper 用户迁移指南

更新日期：2026-10-22。

## Codex 配置

网关与对应 Key 一起保存在当前用户私有的 `~/.codex/config.toml`，使用受管 provider 的 `experimental_bearer_token` 和 `wire_api="responses"`。两者通过同一次文件替换生效，应用启动和独立终端启动均读取该配置。

- 上一版文件密钥会继续正确读取，显式空值不会回退到陈旧全局 Key。
- 对明确配置 `env_key="CUSTOM_OPENAI_API_KEY"` 的旧文件，只读取得旧 Key；确认目标并保存后迁移到同文件配置。新版本不写入、删除或广播全局环境变量。
- 保存后重新启动 Codex，使其重新加载文件。已运行的会话可能继续使用启动时的配置。
- 活动 profile 指向其他 provider、文件损坏或有不能安全迁移的自定义参数时，会拒绝保存并保留原文件。请先核对配置，不要删除安全规则。
- 第三方 CLI 必须读到该 Key，因此配置和备份仍是权限受限的明文。不要把文件原文发到工单或聊天。

如果不再使用旧环境配置，可在确认所有旧启动方式均已迁移后自行清理旧环境项，并按需要在服务端轮换旧 Key；本地删除不等同服务端撤销。

## 登录凭据

Windows 使用当前用户 DPAPI，macOS 使用用户 Keychain，Linux 使用 Secret Service。系统服务不可用或会话迁移失败时，应用会停止自动恢复并提示重新登录，不会退回明文长期会话或同目录主密钥。

macOS 用户需要解锁当前用户钥匙串，并核对系统访问提示中的应用身份。Linux 用户需要桌面会话中可用的 Secret Service，例如提供该接口的 gnome-keyring；仅安装密码管理器或看到进程存在，不能证明接口已就绪。可让管理员检查用户 D-Bus 会话与 `org.freedesktop.secrets` 服务。

旧 Unix 自制密文无法安全自动迁移，需要重新登录。新凭据写入、读回验证和正式提交成功后才会激活会话。更换 Windows 用户或无法访问原 DPAPI 用户资料时，也需要重新登录。

## WorkBuddy 配置冲突

应用为多个兼容配置保留事务记录：`~/.ai-helper/workbuddy-transaction.json`。

- 未完成事务只在当前文件仍属于事务记录的已知版本时恢复。
- 发现其他程序后续修改时，停止覆盖并保留当前文件与事务记录，错误提示会指出冲突路径。
- 已完成事务恢复时保留第三方后续修改；遇到缺失目标时停止自动恢复，避免悄悄重建已删除的配置。
- 有效父目录链接保持不变；损坏链接按平台删除链接本身，不递归处理目标。

发生冲突后先停止双方写入，检查错误路径的权限、磁盘空间和配置状态。让维护人员核对当前文件与事务快照后处理冲突，再重试；不要直接清空配置、覆盖未知版本或删除未核对的恢复记录。

事务记录可能含第三方 CLI 的明文 Key。不要直接打印并提交到工单，也不要把完整记录上传到群聊。反馈时提供操作步骤、路径和脱敏错误信息即可。

普通文件系统没有跨文件的瞬时原子提交，也不能完全阻止不遵守锁的外部程序在最后一次检查与替换之间写入。应用会检测可观察到的版本冲突，不能把该机制理解为所有外部编辑器都遵守本应用锁。

## 额度与本地预算

余额、Token 和日志显示服务端原始平台额度。没有确认的服务端单位/货币契约时显示“换算不可用”；未知额度不显示为零或免费。平台币值以服务端权威契约为准。

本地图片预算限制请求次数，默认关闭，不能替代服务端账户金额硬限，也不能约束从其他客户端直接发起的消费。服务端额度预留、并发限制、幂等记账和会话撤销仍由服务端实施。

## 验证与反馈

本地完整回归入口为 `scripts/verify-improvements.ps1`。默认单元测试使用临时目录和内存凭据后端；Windows DPAPI 检查仅处理合成值。

macOS/Linux 原生凭据验收在一次性 CI runner 中运行：`scripts/test-native-credentials.sh`。该脚本要求显式开启并创建临时钥匙串或私有 D-Bus/Secret Service，不能在个人环境中直接套用 CI 标志。

`scripts/test-macos-release-artifacts.mjs` 验证真实双架构 Mach-O、DMG 挂载、更新签名与生产 Rust 验签。它不安装或启动产品，也不代表 Apple 签名、公证或旧版升级已验收。

问题反馈地址：[TF49/AI-Helper Issues](https://github.com/TF49/AI-Helper/issues)。请移除 Key、Cookie、会话内容和其他个人信息。
